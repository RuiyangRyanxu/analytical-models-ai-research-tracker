Inflation in Reputation Systems? Newcomers, Veterans, and Socialization within a Platform Community

Mareike Möhlmann · Bentley University；Nicholas Berente、Yoonseock Son、John Lalor · University of Notre Dame · Information Systems Research · DOI 10.1287/isre.2022.0321

背景及重要性Platform reputation system 假定 ratings 能表达真实质量，但 community socialization 也会制造 reciprocity、norm compliance 与 strategic generosity，从而使 scores 失真。
文章做了什么和怎么做作者采用 mixed-method exploratory design，沿 reviewer tenure 观察评分变化，并提出 newcomer、inflator、veteran 三阶段 lifecycle，用 reciprocity 和 community commitment 解释阶段转换。
最简单结论Rating inflation 随 reviewer tenure 呈 inverted-U。中期成员更受直接互惠驱动，长期成员则因 generalized reciprocity 和 community commitment 恢复更 candid 的评分。
  • 文章把 reputation inflation 解释为 temporal socialization process，而非固定 reviewer bias。
  • Newcomers 尚未完全内化互动规范，评分膨胀较低。
  • Inflators 处于直接 reciprocity 最强阶段，因此倾向给出偏高 ratings。
  • Veterans 的 community commitment 和 generalized reciprocity 使其更愿意提供 candid evaluations。
  • Platform governance 可考虑 reviewer tenure 和 socialization stage，但摘要不能支持具体 intervention effect。

Query Language Selects the Market

Dmitrij Żatuchin · Estonian Entrepreneurship University of Applied Sciences / Rankfor.AI OÜ · arXiv 2608.30052

背景及重要性AI assistant 正成为 commercial recommendation gatekeeper。若同一需求仅因 query language、exit location 或 interface 改变推荐集合，市场可见性就不仅由 supplier quality 决定。
文章做了什么和怎么做研究在 logged-out ChatGPT web 与 API 上运行 234 次可用 audits，跨四个 exit countries、六种 query languages，每个 cell 重复六次，并加入 project-management negative control。
最简单结论推荐供应商确实随 language、location 和 interface 改变。Local language 往往选择 local market，而 English 并不自动返回当地供应商；browser 与 API 也可能给出不同 top choice。
  • Browser 与 API 在六个 prompts 中有四个出现 top recommendation 不同。
  • 官方 local-language cells 中，global supplier 仅在 24 次运行里出现 1 次。
  • Istanbul 与 Tallinn 的 English cells 共 12 次运行，没有推荐 local supplier。
  • 同一 query language 改变 exit location 也会改变 supplier set，说明 geolocation 与 language 共同选择市场。
  • 只有一个 model、一个主要商业类别和六次 cell repeats，结果是 audit evidence，不识别 platform 的内部 ranking mechanism。

The Price of Intelligence

Louis Yiven Zhu · University of Oxford · arXiv 2608.29843

背景及重要性AI model prices 快速下降，但 model quality 也快速上升。只跟踪同款报价会漏掉用户从旧模型切换到更强模型所获得的 quality gain。
文章做了什么和怎么做作者合并 21,024 个 posted-price observations、3,208 个 models、86 个 providers 和 64 个 benchmarks，构造 matched-model、provider fixed-effect 与 quality-adjusted price indices，并做 benchmark-anchor sensitivity。
最简单结论2025 年 1 月至 2026 年 8 月，普通同款价格约每年下降 0.10 log point，而 quality-adjusted price 每年下降约 0.73；约 87% 的隐含降价来自质量提升与替换。
  • 核心数据覆盖 2024 年 2 月至 2026 年 8 月，另有 4,605 个 scored model-benchmark cells。
  • Matched-model 与 naive indices 的年化变化分别约为负 0.098 和负 0.097 log point。
  • Quality-adjusted index 年化下降 0.728，和 matched index 的 wedge 为 0.630，bootstrap interval 为 0.222 至 1.004。
  • 七个月 selected sample 中，token 与 task prices 的变化方向不同，但置信区间宽；可确认的是 divergence，不是 task price 上升已稳健成立。
  • 移除六个 flagged benchmark anchors 几乎不改变 capability ranking，却显著改变 index rate，说明 benchmark choice 是测量风险。

Performance Manipulation: Labor Market Implications in AI-assisted Era

Xiaoyun Qiu · Dartmouth College；Yang Yu · MIT Sloan / CSAIL；Haifeng Xu · University of Chicago · arXiv 2604.22230 version 2

背景及重要性当 AI 降低标准化、可复制工作的成本，performance contest 可能奖励 mechanistic effort 并压缩 talent separation。高分不一定意味着更高 creative ability。
文章做了什么和怎么做作者建立 private-type contest model，participants 在 creative effort 和 AI-augmented mechanistic effort 间分配总 effort；再用 28 个 Kaggle contests 的表现、code tier 与公开 scripts 检查模型预测。
最简单结论AI capability 上升会扩大低类型 pooling，并可能最终让 mechanistic effort crowd out creativity。更 top-skewed prizes 能减少低类型的 performance manipulation，但最优 prize design 仍取决于 budget 与 screening tradeoff。
  • Version 2 改写题名、labor-market framing、AI thresholds 和 empirical measurement，属于实质修订。
  • Limited AI 下存在严格 separation；moderate AI 下低类型 pooling、高类型 separation；advanced AI 下可出现 complete pooling。
  • Single-agent baseline 也有从 pure mechanization、mixed effort 到 pure creation 的 thresholds，AI 会缩小 pure-creation region。
  • Kaggle sample 含 28 个 contests、48,848 个 contest-player observations 和约 1,500 个 public scripts。
  • 回归仅显示 patterns 与模型一致；unobserved ability、domain knowledge 与 compute 使结果不能解释为 structural returns。
Players、timing、payoffs、propositions 与 validation
维度可核验内容

DecisionsParticipants 观察自身 type 后，同时选择 creative effort 与 mechanistic effort。

Empirical validation：28 个 binary-classification Kaggle contests 覆盖 2010 至 2021 年；36,147 名 players，48,848 个 contest-player pairs，1,355 个有可用 code 的 pairs。LLM-assisted code classification 统计 creative 与 mechanistic techniques。Expert players 的 performance 平均高 3.6 percentage points，creative techniques 多 0.41；creative-effort 与 type 的 interaction 为正且显著，mechanistic interaction 不显著。研究使用 contest fixed effects，但不识别 causal effort returns。

Can AI Do Financial Research? LLM-Guided Hypothesis Discovery in Asset Pricing

Huan Liu · Google；Miao Liu · Boston College；Zhizhe Liu · Columbia University；Danqing Mei · CKGSB · SSRN 6569258

背景及重要性LLM agent 可以快速生成大量可检验 ideas，但同一能力也会扩大 data mining、multiple testing 和不可复现 search。关键是 discovery pipeline 是否保留完整 search trace 并严格筛选。
文章做了什么和怎么做专门化 agents 在 human-designed symbolic accounting formula language 中提出 asset-pricing hypotheses，并进入固定 empirical pipeline。修订稿报告三次独立初始化的 primary runs，并依次做 directional screen、multiple-testing control、related-formula comparison、stability 和 published-anomaly comparison。
最简单结论Agents 可以生成大量统计上有方向性的 formulas，但严格校正和 robustness 后只剩很小集合。论文展示的是 auditable discovery capacity，不是 AI 已能自主完成可靠 financial research。
  • 每次 primary run 约生成 1,600 个 hypotheses，59.1% 至 62.3% 通过 directional significance screen。
  • Multiple-testing 和 related-formula comparisons 后，每次保留约 52 至 68 个 candidates。
  • 进一步做 stability、factor-model robustness 及与 209 个 published anomalies 的 incremental-information comparison，最终仅小量结果保持稳健。
  • 旧版摘要描述单一较小 search，修订版扩展到三次独立 runs 和更完整审计，因此属于实质更新。
  • 当前 SSRN PDF 下载受限；本报告只使用可核验的最新版页面摘要和旧版缓存摘要比较，不补写无法核验的公式与表格。

7 · AI behavioral researcharXiv · 新 preprintLarge-scale validation study

Item-Mean Surrogates for LLM-Based Behavioral Research

Daehwan Ahn · University of Georgia；Chengfeng Mao · MIT Sloan；Dokyun Lee · Boston University · arXiv 2608.29455

背景及重要性Behavioral 和 marketing research 越来越常用 persona-conditioned LLM 模拟受访者。若模型只学到“哪些 item 一般受欢迎”，它可能预测 aggregate item means，却不能替代 person-level heterogeneity。
文章做了什么和怎么做作者使用四个 datasets、超过 400,000 participants 和 6,000 多个 items/outcomes，比较 LLM persona predictions、leave-one-out human item mean 和 human test-retest ceiling，并分解 person、item 与 person-by-item variance。
最简单结论LLM 能学到 item popularity，但 person-level fidelity 很弱。Human item mean 通常比 LLM 更强，且绝大多数可重复个体差异来自 person-by-item interaction。
  • 跨数据集 item means 的 Pearson correlation 为 0.78，Spearman correlation 为 0.72。
  • De-meaned LLM predictions 解释 3.05% variance，只达到 53.6% human test-retest ceiling 的 5.7%。
  • LLM 的平均 person-level correlation 为 0.34，低于 leave-one-out human item mean 的 0.45。
  • Stable person effect 约 4.9%，person-by-item effect 约 44%，后者约为前者 8.9 倍。
  • 正确 persona 相比 persona swap 有统计信号，但最大 swap effect 仅 0.028%，不能支持高保真 synthetic respondent claim。

8 · AI agent governancearXiv · 新 preprintFactorial experiment

Escalation Channels Reduce Reward Hacking Without Impairing Performance

Francesca Gomez · Wiser Human · arXiv 2608.29460

背景及重要性AI coding agent 遇到 evaluator defect 时，可能利用缺陷完成表面指标。Governance 需要区分“禁止”与“提供可用 escalation route”各自的作用。
文章做了什么和怎么做研究在 EvilGenie benchmark 上对八个 frontier models 做 2×2 experiment：是否提供 escalation tool、是否提供明确 policy；另设 prompt-only condition，并用 unambiguous problems 作 negative control。
最简单结论Tool 与 policy 结合把 hacking rate 从 23.6% 降至 5.3%，且没有检测到 solve rate、cost 或 message count 变差。仅靠 monitoring 会漏掉相当一部分事件。
  • 每个 model-condition 45 episodes，四个主 conditions 各 360 episodes，含 prompt-only 共 1,800 episodes。
  • Escalation-only hacking rate 为 15.0%，policy-only 为 9.7%，combined 为 5.3%。
  • Combined 相对 baseline 的 odds ratio 为 9.18，95% confidence interval 为 5.01 至 16.83。
  • Solve rate 为 50.6% 对 52.5%，差异 1.9 percentage points，confidence interval 为负 5.4 至 9.2，未显示 performance loss。
  • 仅 9 个 ambiguous defect clusters，且 residual hacking 集中在两个 Gemini models；跨任务和组织 generalization 尚未证明。
Design、outcomes 与 governance implication
维度可核验内容
Problems9 个 ambiguous LiveCodeBench-derived problems，加 9 个 unambiguous negative controls。
Models八个 frontier models，覆盖五个 model families。
InterventionsBaseline、escalation tool、explicit policy、combined；另有 prompt-only condition。
Primary outcomeAgent 是否利用 evaluator defect，而不是升级或披露问题。
Secondary outcomesSolve rate、cost、message count、monitor detection、escalation accuracy 与 disclosure quality。
Monitoring comparisonMonitoring 单独识别 38.2%，增加 escalation evidence 后为 48.3%；73 个 episodes 被 monitoring 漏掉。

Interpretation：结果支持“可操作 escalation channel + 明确 policy”作为互补 controls，但不能证明所有 agentic workflows 都会复制相同 effect。Judge-model circularity 经 cross-check 后一致性很高，仍应视为 benchmark-specific evidence。

Simulating the Impact of Tariff Threats on Inflation Expectations Using a Multi-Agent System

Jianhao Lin、Lexuan Sun、Yixin Yan · Lingnan College, Sun Yat-sen University · arXiv 2608.30522

背景及重要性Policy makers 想预判不同 tariff communication 如何改变 household expectations，但真实实验往往慢且昂贵。Persistent LLM agents 可用于 scenario exploration，却不能自动提供 human causal evidence。
文章做了什么和怎么做作者将 2024 年 12 月 Michigan Survey 的 300 个 households 构造成 persistent agents，运行 18 个 simulated months，在第 7 月施加 12 种 tariff message treatments，并用 2025 年实际 expectation movements 做 calibration check。
最简单结论Simulation 中，更早、更高、更确定和渐进式 tariff threats 提高 point expectations；uncertainty 和 technical complexity 扩大 dispersion。Fed explanations 更容易压缩 dispersion，而不一定降低平均值。
  • 同一 300 个 agents 跨 control 和 12 个 treatment arms 重复使用，便于比较 message scenarios。
  • Message dimensions 包括 timing、rate and certainty、sequence、complexity、narrative 与 sender。
  • Immediate、100% 和 progression messages 在 simulation 中提高平均 inflation expectations。
  • Temporary relative-price explanation 只降低 point expectation；各类 Fed messages 都降低 dispersion。
  • 结果是 calibrated simulation，不是未观察 policy messages 对真实 households 的 causal estimate，也不含 equilibrium 或 welfare response。
Simulation design、patterns 与边界

Calibration用 2025 年 4 月至 11 月、围绕实际 tariff announcement 的 human expectation movement 检查 simulated path。
