1 · Platform governance期刊 onlinenatural experiments

Generative AI, Platform Stances, and Content Creator Behavior

Hongxian Huang（NYU Stern）、Runshan Fu（Carnegie Mellon Heinz）、Anindya Ghose（NYU Stern）

背景及重要性内容平台面对 GenAI 时不仅选择功能，还公开表达价值立场；这一信号可能改变创作者对替代风险、内容质量与版权保护的判断。
文章做了什么和怎么做作者利用两个独立 natural experiments：Lofter 上线 AI 图像生成器，以及 Graffiti Kingdom 禁止 AI-generated art，比较政策前后创作者活动变化。
最简单结论支持 GenAI 的平台立场降低创作者活动，反对 AI 内容的立场提高活动；结果更符合 stance signaling，而非单纯功能使用或执法强度。
  • 平台的技术立场本身会改变供给侧参与，并非只有 fee、流量分配和功能设计才重要。
  • Lofter 的活动下降集中于更受欢迎、multi-homing 和更排斥 AI 的创作者。
  • 创作者担忧主要涉及被替代、低质量内容挤压以及版权风险。
  • Graffiti Kingdom 的禁止政策提高创作者活动，提供方向相反的外部验证。
  • 治理含义是：平台部署 GenAI 时需要把创作者产权、可见性与申诉机制作为配套制度，而非只发布产品声明。
研究设计、机制、结果与识别边界
维度核验内容
研究问题平台对 GenAI 的公开立场是否通过信号渠道改变内容创作者的持续供给。
研究设计两个独立平台事件构成方向相反的 natural experiments：推出 AI image generator 与禁止 AI-generated art。
理论机制平台立场更新创作者对未来替代、内容生态质量、知识产权保护和平台承诺的预期。
异质性创作者 popularity、multi-homing 和 AI aversion 调节 Lofter 事件后的活动下降。
识别边界可访问摘要未披露精确样本量、事件窗口和估计量；因此本报告不补写未经全文核验的系数或 parallel-trends 结果。

原文未在可访问摘要中列编号 hypothesis。可检验经验预测是：当平台立场提高创作者感知替代风险且削弱产权保护预期时，创作者供给下降；反向立场产生相反变化。此表述是对摘要机制的结构化整理，不是原文编号假设。

2 · Platform labor governance期刊 onlineprocess theory

How Platform Workers Contest Algorithmic Management: Theorizing the Dynamics of Algoactivistic Practices

Jennifer Jiang、Martin Wiener、Alexander Benlian、Martin Adam、Magnus Mähring

背景及重要性平台用算法分配任务、评价绩效并施加控制，但劳动者并非被动接受；他们会学习规则、利用市场与表达渠道来重新争取行动空间。
文章做了什么和怎么做文章以 Uber 为 extreme case，结合 topic modeling 与 qualitative coding，使用 computer-assisted grounded theory 构建 contestation 的动态过程模型。
最简单结论劳动者先重新评估算法控制地形，再探索可用资源，最终以自我优化、疏离或正面对抗来回应；实践形式取决于资源、目标和可持续性。
  • 过程分为 reassessing terrain、exploring opportunities 与 contesting terrain 三个阶段。
  • 劳动者动员的资源包括对算法的理解、市场替代机会和 voice channels。
  • self-optimizing 并非单纯顺从，它可能是利用算法规则改善收益的策略性回应。
  • distancing 与 confronting 的目标、强度和持续时间不同，不能合并为单一 resistance 指标。
  • 平台治理需要区分短期行为纠偏与长期制度性不满，并提供可见、可复核的决策与申诉路径。
数据、分析程序、理论构件与边界
分析主体平台劳动者、平台的 algorithmic management system、市场机会以及 formal / informal voice channels。
分析程序topic modeling 用于发现大规模材料中的主题结构，qualitative coding 用于追踪行动、目标和时序，二者共同服务 grounded theory 建构。
理论输出过程模型连接 control terrain、可动员资源与三类 contestation practices，并区分其逻辑、目标与 durability。

原文未在可访问摘要中提出编号 hypothesis。本文是 inductive process theory，不宜把构件关系改写为待估计的线性因果模型。可进一步检验的预测是：算法可解释性、外部工作机会和有效 voice channels 会改变劳动者采用何种 contestation practice。

局限：Uber extreme case 有助于机制显现，但跨平台与跨制度环境的外推需要比较研究；摘要未披露材料规模、时间跨度和 coding reliability 数值。

状态与可用性：Information Systems Research，2026-08-10 online，DOI 10.1287/isre.2024.0927；期刊摘要可访问，完整期刊正文的开放下载状态本次未确认。

3 · User-steerable recommendation新论文补检production system + A/B test

Shape Your Feed: An LLM-based Agentic System for Conversational Recommendation

Ziyun Xu、Bosen Ding、Yue Zhang、Ji Qi、Qingyuan Song、Jizhou Huang、Liwei Wang、Jeffrey Santelli、Yue Weng、Qichao Que、Zhenheng Yang、Junfeng Pan、Linhong Zhu（Meta Platforms）

背景及重要性传统 feed 从 clicks 与 dwell time 推断偏好，用户很难表达“少一点某类内容、多一点某种风格”等即时且细粒度的约束。
文章做了什么和怎么做作者构建 Perception、Serving 与 Self-Evolution 三条 flow，把文本、语音和界面反馈写入 persistent Semantic Profile，并在 production traffic 上做 offline evaluation 和 online A/B test。
最简单结论LLM 可以成为用户与 ranking stack 之间的结构化控制层：它解释意图、维护状态并调整候选，但底层 engagement model 仍作为质量与规模约束。
  • Perception Flow 把非结构化反馈转为可编辑、可持续更新的 Semantic Profile。
  • Serving Flow 在既有生产候选上做 augmentation、pruning 与 re-ranking，避免脱离 catalog 生成内容。
  • Self-Evolution Flow 结合 online behavior、DPO 与 LLM-as-a-Judge 更新政策。
  • offline alignment accuracy 为 98.85%；生产 A/B test 改善 feed relevance 与 user sentiment，但摘要未披露效应量。
  • 治理价值在于把用户的明确意图加入推荐目标，同时保留 base ranking score 作为约束。
系统架构、评价、结果与部署边界
模块决策与约束
Perception Flow解析 multimodal interaction、识别意图、去重与冲突处理，并维护跨轮次 Semantic Profile。
Serving Flow从有效 inventory 中补充候选，以语义匹配分数实施 hard pruning，再与生产 engagement prediction 共同重排。
Self-Evolution Flow用人工判断、在线行为和 dual-feedback alignment 更新 perception 与 serving policies，并向底层模型传播语义信号。
评价offline accuracy、few-shot 和 conventional ranking baselines、独立 human evaluation、production A/B test、ablation 与 system efficiency。

不是经济学 structural model。文中公式描述系统状态更新和排序操作，不代表用户效用或平台利润最大化；因此不把这些工程方程改写为福利模型。

识别边界：论文报告大规模线上实验，但可访问摘要未给出样本量、实验时长及核心 effect size；“改善”可核验，经济量级仍需完整结果表。

4 · AI and organizational production新论文补检longitudinal enterprise study

Characterizing the Quality Profile of AI-Generated C++ in Production

Michael Tran、Fred Lewis、Kun Yang、Saksham Thakur、Aditya Kini、Aditya Patil、Milad Hashemi、Parthasarathy Ranganathan

背景及重要性AI coding 的速度收益可能把成本转移到 review、维护和 production compute；只用 benchmark correctness 无法观察这类下游组织成本。
文章做了什么和怎么做研究跟踪一家大型科技企业 2025 年 4 月至 2026 年 4 月的 352 万次 code changes，以 authoring-time provenance 连接 static findings、review、reliability 与 function-level compute，并测试 targeted feedback。
最简单结论AI-generated C++ 并非全面更差，但问题高度集中在 interface / coupling 与 copy / allocation；这些结构差异伴随更多 review effort 和 5%–8% compute 增长，可被针对性反馈部分缓解。
  • AI-generated code 在已知 provenance 的提交代码中从 28.99% 上升至 68.62%。
  • AI-heavy changes 更大、触及更多文件且更偏向新代码，因此简单均值比较会混入 change structure。
  • interface / coupling 与 copy / allocation 两类占正向 static issue gap 的 82.21%。
  • AI-heavy code 关联 1.92 倍 blocking comments、1.39 倍总评论、1.24 倍 review iterations 与 1.19 倍 time-to-merge。
  • taxonomy-informed feedback 使目标 static warnings 下降 11.1%，说明问题可以被 tool design 定向治理。
数据、变量、比较设计、结果与限制
维度核验内容
样本352 万次提交变化；1046 万行有信息量 provenance 的 C++；约 35 万次可做 static analysis 的 reviewable changes；约 7 万个 function-level compute observations。
核心变量byte-level AI share、change size、new-code ratio、static issue taxonomy、comments、review latency、build / revert signals、CPU 与 memory。
比较策略以 month、change size、organizational slice、author / team controls 与 new-code status 分层比较；作者明确不用这一设计声称全面 causal effect。
干预50 个 C++ functions，三个 prompt stages、每阶段三次独立运行；在验证排除前形成 450 个 implementations。
结果边界build failure 约为 1.3 倍，但 revert rate 约为 0.9 倍；质量差异不是所有 outcome 同方向，也不是所有 issue categories 普遍恶化。

原文按四个 research questions 组织，而非编号 hypotheses。可检验预测是：将 high-support issue taxonomy 作为 authoring-time feedback，会降低相应 static findings，并改善关联的 compute efficiency。

局限：单一匿名企业；模型与工具组合在窗口内变化；observational cohort comparisons 仍可能存在 selection；targeted intervention 是合成 benchmark，不等同于长期生产部署。

5 · Algorithm providers and competition旧论文新版本补检dynamic conduct test

Shared Bidding Algorithms and Competition: Evidence from Electricity Markets

Nicolas Eschenbaum（Swiss Economics, Zürich）

背景及重要性竞争企业可能把高频决策外包给同一个软件 provider；即使企业所有权独立，上游软件层也可能同步行动并改变竞争激励。
文章做了什么和怎么做作者把澳大利亚电力市场电池的五分钟级出价与 provider 映射连接，利用 2025 年信息披露改革分析同步性，再估计储能动态价值并 counterfactual reclearing。
最简单结论同一 provider 服务的不同所有者电池会放弃本可盈利的 dispatch，以避免压低同 provider 对手利润；该现象只在 near-margin capacity share 超过约 30% 时出现。
  • 同 provider 电池的 bid level 与 rebid timing 更同步，且在 scarcity state 更可观察后同步性进一步提高。
  • conduct test 先估计 stored energy 的 dynamic opportunity cost，再比较局部 deviation 的反事实利润。
  • 估计的跨所有者利润权重接近 1，而 owner-level benchmark 对应权重为 0。
  • 效应集中在 provider 的 near-margin capacity share 超过约 30% 的状态，installed capacity concentration 并非充分统计量。
  • 按 2025 年电池 fleet 估算，相关行为给消费者造成约每年 550 万澳元成本。
参与者、时序、识别、均衡含义与稳健性
参与者与决策电池 owners 设定高层目标和约束，第三方 provider 的软件生成并提交 bid stacks；市场每五分钟同时结算 energy 与 ancillary-service markets。
动态约束当前 dispatch 改变 state of charge，从而影响未来收益；因此单期出价 deviation 必须计入 stored energy 的 continuation value。
行为参数参数为 0 表示只最大化 owner 自身利润，参数为 1 表示完全内化同 provider、不同 owner 电池的利润；估计值接近后者。
λ=0owner-level incentivesλ=1full same-provider profit internalization
这是原文对 conduct parameter 两个 benchmark 的明确定义；估计值接近 1。完整动态目标还包含 state transition、技术约束与 continuation value。
识别环节内容
同步性2025 年 7 月披露改革提高 scarcity-state observability，用于比较改革前后同 provider bids 的 co-movement。
动态价值估计 Bellman continuation value，得到每个电池 state of charge 的机会成本。
conduct test把 withheld capacity 移至 marginal band 并重新清算 energy 与 ancillary-service markets，形成 revealed-preference moment inequalities。
阈值跨所有者利润内化只在 provider 的 near-margin share 约高于 30% 时出现。
稳健性包括 omitted owner-level cost bounds、permutation placebo、matched provider placebo、lead-time split、same-owner positive control 与 alternative concentration moderator。

公式审核：核心结论依赖动态估计与反事实重新清算，不宜用脱离状态转移、技术约束和 continuation value 的单一简式代替；除上述原文 benchmark 外不补写缩写公式。
