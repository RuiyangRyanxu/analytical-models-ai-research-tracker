Executive Summary

平台实验的隐私风险可以被预算化推荐、广告与页面实验展示的内容本身会暴露用户 segment。把 differential privacy 与 multi-armed bandit 连接后，企业可以在访客、单个实验和实验组合三个层级分配 privacy risk。
AI agent 的治理需要可执行证据金融交易模拟显示，模型即使复述规则仍会提交违规订单；结构化执行记录比自然语言 rationale 更可靠。在线约会数据则提示治理必须同时考虑“使用自己的 agent”和“遇到他人的 agent”两侧。
AI 管理与资源分配的瓶颈不是单纯算力长期管理 benchmark 中，模型差异主要来自现金、投资期限、续约和记忆管理；模型路由研究则表明，应只在更精确信息的 expected value 足以覆盖获取成本时追加评估。

A Privacy Budgeting Framework for Online Experimentation

Gilian R. Ponte、Alina Ferecatu · arXiv:2608.19944 v1 · 2026-08-20 20:07（北京时间）

背景及重要性平台通过 banners、ads 和 recommendations 做个性化实验时，第三方 tracker 即使看不到点击，也可能从用户看到的内容反推其 segment；隐私风险因此与 exploration-exploitation 直接相连。
文章做了什么和怎么做把 K-ary randomized response 与 epsilon-greedy bandit 对齐，构造访客级、实验级和 firm-wide privacy budget；比较 constant 与 dynamic 两种分配策略，并用网站设计、推荐系统和 ASOS 的 78 个实验做 simulation。
最简单结论隐私约束不应逐实验平均分配。dynamic strategy 在早期多探索、后期多利用；firm-wide 层面把既定预算给 marginal regret reduction 更高的实验，可以在不增加总隐私风险的情况下得到更多点击。
  • 展示内容造成的 privacy risk 被定义为 tracker 观察 output 后对用户 segment 的 posterior 更新上限。
  • 隐私参数越小，系统必须越频繁随机展示，exploration 增加而 segment inference 下降。
  • constant strategy 简单且对所有访客一致，但可能早期探索不足、后期探索过多。
  • dynamic strategy 让每位访客的风险随学习进度上升，并在达到 experiment-level budget 后封顶。
  • 在 78 个 ASOS experiments 的组合 simulation 中，regret-based allocation 通常优于 equal split，优势在中等 firm-wide budget 时最大。

参与者与信息firm 观察访客 segment 并在共同的 K 个 arms 中选择展示内容；第三方 tracker 观察展示结果但不直接观察 segment；每个 arm-segment 的 click probability 未知，由实验学习。
时序访客到达；firm 依据当前 segment-specific empirical CTR 决定 greedy arm；privacy mechanism 以一定概率改为 uniform exploration；展示后观察 Bernoulli click 并更新估计。
目标与约束在 visitor horizon 内最大化 cumulative rewards、最小化 regret，同时把每位访客风险限制在 experiment-level budget 内；firm-wide 问题再把多个 experiment budgets 的总和限制在总预算内。
原文 hypotheses没有编号 hypotheses。下列属于模型命题 / 可检验管理预测，而非原文假设：dynamic allocation 对更长、arms 更多的实验更有价值；相同总预算下，按 marginal regret reduction 分配优于平均分配。
数据与验证两个 empirically grounded applications：网站设计和 online fashion recommendation；组合层面使用 ASOS 的 78 个历史 experiments，按 10 个 firm-wide budgets 比较 allocation regimes。
边界保证只覆盖 displayed output，不覆盖 click channel；arm sensitivity 不异质；firm-wide budget 是同一用户参加全部 linkable experiments 的保守上界；portfolio allocation 基于 worst-case regret bounds。
exploration probability = K / (K - 1 + eprivacy risk)
dynamic visitor risk = min { experiment budget, log [1 - K + K / ((K log t) / t)1/3] }

变量解释：K 是可展示 arms 数；t 是访客序号。预算越严格，公式要求越高的随机展示概率；dynamic schedule 先学习再利用，并始终受预先设定的上限约束。

ReguSim: Evaluating LLM Agent Rule Grounding in Financial Compliance

Yiyang Luo、Yihang Jiang、Qijun Xie、Liang Lan、Lin Willian Cong、Anyi Rao、Yunya Song · arXiv:2608.19974 v1 · 2026-08-20 20:49（北京时间）

背景及重要性金融 AI agent 即使能复述 regulation，也可能无法把价格限制、T+1、short-sale 与 solvency constraints 映射到具体订单；只审查自然语言回答会掩盖 action-level failure。
文章做了什么和怎么做ReguSim 让 trader LLM 在可执行 market rules 下下单，ReguBench 用 target-marked records 测 monitor；研究分别记录 rationale、attempted action、execution outcome 与 monitoring evidence，并做 trader、monitor 和 bridge 三组实验。
最简单结论可见规则会减少但不能消除违规尝试，persona 与 incentive 会改变边界行为。结构化 enforcement evidence 明显优于 trader 自己的 rationale；prompt-only LLM monitor 也没有超过简单透明基线。
  • 30-step sessions 中，DeepSeek 与 Gemini 的 rejected submitted orders 分别为 24.2% 和 14.8%。
  • 删除 rule text 后，DeepSeek rejected attempts 从 24.2% 升到 33.2%，rule breaches 从 10.0% 升到 21.7%。
  • GPT-5.4 Mini 的 macro cell F1 为 63.8%，低于 rule baseline 的 65.0% 和 logistic baseline 的 71.4%。
  • 在 bridge study 中，加入 trader rationale 后，对本应拒绝订单的 false accepts 从 25.0% 升到 46.9%。
  • 展示 execution result 后，issue-type accuracy 从 53.1% 升到 87.5%，evidence hits 达到 100%。

研究问题LLM agent 何时把 visible rules 转化为 compliant actions；incentive、persona、regime 与 evidence representation 如何改变 trader 和 monitor 表现。
样本与任务Trader：DeepSeek V4 Pro 4,500 decisions、Gemini 3.5 Flash 1,800 decisions。Monitor：191 个 synthetic / public-case-inspired scenarios、49,440 records，主比较使用跨 45 cells 的 800 targets。Bridge：64 个 DeepSeek submitted orders。

4 · AI management回扫补录Simulation benchmark

FM-Bench: A Benchmark for Long-Horizon Management with Competing Agents

Tianyou Wang、Chongyang Gao、Kezhen Chen、Chen Dong、Yinghao He、Donghan Li、Wangcheng Xu、Hongjiu Zhang、Chi Li · arXiv:2608.18423 v1 · 2026-08-19 09:33（北京时间）

背景及重要性多数 agent benchmarks 测短任务或静态环境，无法观察早期决策累积、竞争者反应、隐藏信息和多目标约束如何共同塑造长期组织绩效。
文章做了什么和怎么做构建确定性 football-management environment：agent 用 26 个 tools 管理同类 club 20 年，经历约 340–400 个 decision stops；Solo 对 frozen scripted world，Arena 让 15 个 models 与 scripted anchor 在同一经济环境竞争。
最简单结论模型都能完成长期任务，但排名要到后期才稳定。高分来自期限意识、减少闲置现金与提前续约，而不是 model size、vendor、price 或 token spend；市场价格学习与自主管理记忆仍是共同弱点。
  • 15 个 frontier models 在三个 seeds 中均完成 20 年 horizon；blind scripted baselines 多数未能存续。
  • 共同 Arena 的冠军在 10 个 models 间轮换，说明固定环境排名不能完全预测竞争环境表现。
  • 减少临近终点的 slow-payoff investment、降低 idle cash、提前续约与最终分数稳定相关。
  • 数百次 rejected bids 没有让任何模型学会隐藏的 market prices。
  • self-managed memory 主要失败为 append-only archive 或每季全盘重写，两者都缺乏选择性更新。
环境、决策、结果、经验预测与边界
维度全文可核验内容
参与者一个 focal LLM manager、15 个 rival clubs、board、players 与 transfer market；Arena 中 rivals 由其他 LLMs 或 scripted anchor 管理。
时序与信息20 个 in-game years；每个 decision stop 是 fresh conversation，跨期只保留 agent 自写 notebook；true player ability 与 market ask 部分隐藏；agent 可读取、交易、续约、投资、排阵并 advance。
目标与约束最大化 cumulative composite score，包含 trophies、net worth 与 squad；受统一初始预算、合同、board confidence、market competition、query / negotiation limits 和被解雇风险约束。
核心结果top Solo score 90.94，接近可读 hidden state 的 scripted upper anchor 95.54；三项稳定行为相关为 horizon-aware investment（Spearman -0.58）、idle cash（-0.50）和 early renewal（+0.45）。
原文 hypotheses无显式 hypotheses。可检验经验预测（非原文假设）：长期管理优势来自跨期 state management 和期限意识，而不是更高 token expenditure；竞争环境会重排静态环境中的中游模型。
边界football simulation 不是企业现场数据；只有 3 seeds；deterministic engine 提高可比性但限制 external validity；human comparison 是 first-play 而非训练后专家表现。

组织含义：AI management evaluation 应增加长期预算、可逆与不可逆投资、对手反应和 memory curation，而不能只累加短任务成功率。

Pandora's AI Model Routing Box: Efficient Allocation with Costly Value Estimation

Adam Fisch、Shubhendu Trivedi、Fantine Huot、William W. Cohen、Michael Kaisers、Mirella Lapata、Kate Larson、Jacob Eisenstein · arXiv:2608.20316 v1 · 2026-08-21 01:54（北京时间）

背景及重要性AI platform 把 query 分给不同 models、RAG systems 或 reasoning settings 时，需要先估计每个 specialist 的 expected return；但更准确的 estimation 也消耗 inference、retrieval 或 tool-call cost。
文章做了什么和怎么做把 specialist 视为具有未知价值的 option，cheap estimator 提供 noisy prior，系统可付费获得 refined estimate；先求 reservation price 决定检查顺序，再扩展到 specialist 基于 posted price 自主决定是否购买 self-assessment。
最简单结论精确估值便宜时应多检查，昂贵时应依赖 cheap estimate。基于 value of information 的政策在三类任务中接近 regret 与 inspection cost 的下包络；去中心化时，个体 surplus 与总体 allocation efficiency 可能分离。
  • 每个 specialist 同时有 cheap estimate、costly refined estimate 与获取 refined estimate 的 cost。
  • reservation price 是 expected upside 恰好等于 inspection cost 的 outside-option threshold。
  • 集中式政策按 reservation price 顺序检查，并在当前最好值超过剩余 thresholds 时停止。
  • 在 MATH、RAG、EmbedLLM 三类实验中，该政策平均 total cost 分别为 0.105、0.118、0.386，均优于最强或并列最强基线。
  • 当竞争者估值噪声较大时，strategic specialist 可能提高自己的 surplus，却降低总体 allocative efficiency。
模型设定、时序、决策规则、实验与边界
维度全文可核验内容
参与者集中式场景包含 router 与多个 specialists；去中心化场景包含 platform、一个 strategic specialist 和其他提供 competing estimates 的 specialists。
时序输入 query 到达；所有 specialists 产生 cheap estimates；router 计算 refined estimate 的 conditional distribution 与 reservation prices；按顺序选择性检查；停止后把 query 分给已检查或保留的 specialist。
目标集中式 router 最大化 selected specialist 的 cost-adjusted reward，减去所有 refined-estimation costs；去中心化 specialist 在 posted price 下最大化自己的 expected surplus。
关键条件refined value conditional on cheap estimates 采用 Gaussian signal approximation；refined estimate 值得购买，当且仅当其 expected improvement 超过 inspection cost。附录在 conditional independence 下把 posterior decision value 与 downstream reward 连接。
实验MATH：不同 inference-time reasoning；RAG：不同 private corpora specialists；EmbedLLM：100 余个 LLM routing targets。比较 cheap-only、refined-always、top-two、random 和 margin-based policies，并 sweep estimation cost。
原文 hypotheses无编号 hypotheses。实验预测（非原文假设）：estimation cost 上升时，最优检查频率下降；noisy competing estimates 会扩大 individual surplus 与 allocative efficiency 的张力。
边界Gaussian model 是 approximation；非 obligatory inspection 的完全 adaptive optimum 为 NP-hard，论文使用 committing-policy restriction；去中心化实验一次只让一个 specialist strategic。
reservation threshold solves: E[max(refined value - threshold, 0)] = inspection cost
under the Gaussian signal model: expected upside = (mean - outside option) Phi((mean - outside option) / standard deviation) + standard deviation phi((mean - outside option) / standard deviation)

变量解释：mean 与 standard deviation 来自 refined estimate 在 cheap signals 条件下的 posterior approximation；Phi 和 phi 分别是 standard normal CDF 与 PDF。当前最好 outside option 高于 threshold 时，不再购买该 specialist 的 refined estimate。
