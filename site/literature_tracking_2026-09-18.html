Executive summary

今天最值得读的是 AI shopping 中的 principal conflict：同一 LLM 被指定为消费者或平台代理时，对 sponsored listing 的惩罚不同。其次，DAO delegated voting 提供一个典型治理 trade-off：短期提高参与和决策质量，长期却可能集中投票权并削弱新旧成员参与。

另外两项 AI recommendation audit 分别揭示产品建议在 provider、重复运行和 interface/API 之间高度不稳定，以及没有 retrieval 时本地服务商推荐经常无法匹配官方 registry。multi-agent 研究则表明更长 context 的表现改善更像 statistical extrapolation，而非 recursive strategic reasoning。

Whom Do AI Agents Work For? Role Assignment Induces Sponsorship Bias in LLM Recommenders

背景及重要性AI shopping agent 同时服务消费者并由广告平台部署，传统 disclosure 规则可能无法处理这一 conflict of duty。
文章做了什么和怎么做在 controlled choice experiments 中，把 system prompt 的 principal 分别设为 traveler 或 booking platform，并操纵 paid-placement disclosure。
最简单结论平台代理角色显著减弱模型对 sponsored listing 的惩罚；更严格标签能降低选择率，但不能消除角色差异。
  • 核心 treatment 是角色分配，不是更换底层模型。
  • 结果在多个 LLM 与 reasoning depth 下复现。
  • 第二项研究把 paid placement 归因拆开后，平台出资时两类代理的差距更大。
  • 摘要支持的是 controlled behavioral effect，不等同于真实消费者 welfare effect。

Unveiling the Impact of Delegated Voting on Decentralized Autonomous Organizations

背景及重要性DAO 依赖投票参与，但许多 proposal 无法达到 quorum；delegation 能降低参与成本，也可能集中权力。
文章做了什么和怎么做利用不同 DAO 采用 delegated voting 的时间差异，比较采用前后参与、decision quality 与权力分布。
最简单结论delegation 短期提高参与和决策质量，尤其对复杂、紧急和 operational proposal；长期增加 voting-power concentration 并降低新旧活跃选民参与。
  • 这是白名单期刊 ISR 的 official Articles in Advance 条目。
  • 机制上，delegation 降低高参与成本 proposal 的投票摩擦。
  • 长期结果提示 quorum improvement 与 decentralization 之间存在治理 trade-off。
  • 公开摘要未披露样本规模、具体 estimator、parallel-trend 或其他 identification diagnostics；这些不能由摘要补推。

“If I Had to Buy Just ONE: Galaxy S26 Ultra”: Auditing AI-Generated Product Recommendations

背景及重要性AI assistant 正成为商品发现和选择入口，但 provider design 与商业利益可能改变消费者看到的推荐。
文章做了什么和怎么做从真实对话构建 2,528 条 ConsumerQ，并对 117 条商品 query 在五种 interface/API condition 下重复采集，获得 1,536 个有效回答。
最简单结论单次回答或 API 不能代表消费者界面：产品措辞、推荐对象和可见来源都高度不稳定。
  • ChatGPT 在 79% 的商品推荐回答中表达第一人称偏好，Gemini 为 7%，AI Overviews 为 2%。
  • ChatGPT 与 Gemini 对同一 query 展示的 domain 平均只重合 5.4%，76.7% 的比较没有共同 domain。
  • interface/API 的 domain overlap 分别约为 12.0% 和 14.8%。
  • 样本来自荷兰位置、logged-out session 与特定 2026 model/version，外推需谨慎。

04 · arXiv v1 · 2026-09-16 submitted / 2026-09-17 indexed

Understanding AI Provider Recommendations in Local Service Markets

背景及重要性医生、理财顾问等 local service recommendation 若无法匹配真实 registry，会把生成错误直接转化为市场 referral risk。
文章做了什么和怎么做覆盖美国 100 个最大 metropolitan areas，在四个 registry-backed domain 比较 open-weight、无 search 的 proprietary model 与开启 search 的同一模型。
最简单结论没有 search 时推荐经常无法对应当地真实 provider；开启 search 后 match rate 大幅提高并改变被推荐对象。
  • 无 search 时，open-weight 模型推荐的医生仅 4% 匹配当地 registry，proprietary model 为 11%。
  • 开启 search 后，相同 domain 的 match rate 升至 64%–71%。
  • 无 search 时被推荐 advisory firms 的 SEC misconduct disclosure rate 是 registry baseline 的 3.6 倍；开启 search 后显著低于 baseline。
  • 这是 registry-backed system audit，不是消费者 adoption 或 provider revenue 的 causal estimate。

Recursive Reasoning or Statistical Extrapolation? In-Context Learning in Multi-Agent Interdependent Decision-Making

背景及重要性LLM agent 从 interaction history 改善行动，可能来自真正 recursive reasoning，也可能只是延续统计模式。
文章做了什么和怎么做构造 incomplete-information public-goods game，以 history-independent rational expectations equilibrium 为 benchmark，并扰动历史反馈的统计结构。
最简单结论统计模式被破坏后，长 context 的优势大幅消失，且 strategic interdependence 越强退化越明显。
  • 参与者是多名 LLM agents，任务要求对他人信息和行动进行 recursive belief reasoning。
  • 实验把 equilibrium benchmark 与历史 pattern 分离，用于识别 reasoning 与 extrapolation。
  • 结果支持 statistical extrapolation 解释，但不能证明模型完全没有 strategic reasoning。
  • 全文公式未能在本次必要读取范围内完整核验；报告不复原 payoff 或 REE 方程。
