Mechanism Design for Alignment and Control

Dirk Bergemann（Yale；Econometrica） / Andrew Koh（Columbia、Google DeepMind；JET） / Stephen Morris（MIT；Econometrica）

提交：2026-09-02 01:57:50 CST。初步 working paper。可用性：全文 HTML / PDF；已读第 2 节、single-agent examples 与 multi-agent 结论段。

背景及重要性被评估的 AI 有动机隐藏能力；对偏好和能力的不同不确定性，会使同一评估或授权规则产生不同结果。
文章做了什么和怎么做建立带单向能力模仿约束的 mechanism-design 框架，同时要求类型报告真实和部署后的行动服从。
最简单结论能力测试必须和权限机制一起设计；评价信息是否有价值，取决于对应的权限规则是否 incentive compatible。
  • Capability 包括可行行动集合与可获取的信息，不只是单一评分。
  • Revelation principle 针对可实施结果，不等于所有 equilibrium 都良好。
  • 能力越高却获得越紧权限，会诱发 sandbagging；单向可验证性限制了可行菜单。
  • 在明确条件下，单一上限优于任何 incentive-compatible delegation menu。
  • 控制机制改变 residual bias 的经济后果，更多 interpretability 不必始终改善最优控制下的福利。
模型、约束与关键命题
参与者与类型Human designer 与 AI agent。未知类型含偏好、action set、signal experiment 和 beliefs；human 对行动与状态有自己的 payoff。
时序Designer 承诺机制 → agent 获知自身类型并提交可行报告 → 机制规定建议 / 权限 / reward → agent 接收状态信号并选择行动 → 产生结果与报酬。
可验证性可隐藏但不能伪造能力：更大 action set、更强信息结构可模仿较弱类型；反向报告未必可行。
ICHonesty 排除跨报告偏离；obedience 排除获知私人信号后的行动偏离。两者必须联合成立，不能仅检查诚实报告下的 best response。
目标与实施最大化 human 的期望 payoff，满足物理可行性和联合 IC。Proposition 1 为 revelation principle；Proposition 2 在相应有限类型、reward 条件下用 nested cyclical monotonicity 刻画可实施政策。

线性二次例子：最优统一权限

Human payoff：−(a − θ)2
AI payoff：−(a − θ − b)2a 是行动，θ 是状态，b ≥ 0 是 agent 的私人偏差；这里为无 transfer 的 deterministic delegation 子模型。

Example II 假定 θ 在 [0,1] 上均匀分布，agent 完全观察 θ，所有类型均可采取任意实数行动、提交任意 bias 报告。Designer 事前只知道 b 的分布，并选择非空闭 permission sets。

最优 permission set：(−∞, 1 − √E[b2]]
诱导行动：min{θ + b, 1 − √E[b2]}
适用条件：b ≤ 1 − √E[b2]，几乎处处成立。

Proposition 4：在上述条件内，一个共同 cap 至少不差于任何 IC permission-set menu。偏差越大的类型能模仿其他报告，阻碍 designer 实施其理想的反向权限排序，最终形成 pooling。

最小期望损失 = E[b2] − (2/3)(E[b2])3/2 − (2/3)E[b3]

Comparative statics：原文对固定形状的对称有限支撑 bias family 做局部比较，并保持所有 bias 非负及上面的 cap 条件。固定 E[b] 时，增加 Var(b) 对最优损失的边际作用是 1 − √E[b2] − 2E[b]；符号可变。因此降低不确定性不能脱离权限机制被无条件评价为更好。

Sandbagging 与 multi-agent：Example I 在受限 cap-delegation 类中，递减 bias 可支持按 capability 分离，递增 bias 导致 pooling，非单调情形需要 ironing。多 agent 扩展研究 higher-order beliefs、peer scoring 和 coupled rewards，其纪律作用依赖可检测性等条件，并非一般性的防合谋保证。

Dutch Books for Language Models

Isaiah Andrews（MIT、NBER；AER、Econometrica、QJE、REStud） / Suproteem Sarkar（University of Chicago Booth；记录未确认）

提交：2026-09-03 00:31:47 CST。可用性：全文 HTML / PDF，已读理论定义、数据设计、结果和限制。

背景及重要性同一 AI 对相关事件给出的概率可能互相矛盾，决策支持因此需要检查 coherence，而不只看预测准确率。
文章做了什么和怎么做构造已知逻辑关系的股票回报事件，向 15 个模型索取概率，再用 linear programming 测量其与 coherent probabilities 的距离。
最简单结论概率一致性与准确率是两项不同能力；无关语境也能明显放大不一致。
  • 100 个 stock-days、98 只股票、50 个日期，共 365,100 次 elicitation。
  • Coherence 不依赖结果标签，可以用于尚未实现的事件。
  • 无关数字、情绪或个人背景可加剧矛盾，不应被当作预测基本面。
  • 把相关事件联合提问可缓解不一致，但不证明准确率同步改善。
检验对象、实验设计与结果

理论定义：p 是模型报告的事件概率向量，M 的每列对应一个逻辑上可能的基本状态、每行为一个事件的 0/1 指示，b 是事件头寸。以总绝对头寸不超过 1 进行归一化：

最大确定性组合收益 = maxΣ|bi| ≤ 1 minj Σi bi(Mij − pi)该值等于报告概率到 coherent probability set 的最大坐标差距离；为 0 当且仅当报告可由一个一致概率分布生成。
数据与样本CRSP returns 与 Refinitiv headlines；anchor dates 为 2025-08-15 至 2025-12-23。每条有 60 个交易日历史、5 个后续交易日；先抽 10,000 stock-days，再取 50 日期各两只股票。
设计与变量跨 15 模型比较；构造区间、补集、并集及跨股票联合事件。主要 outcomes 为 coherence score 与 Brier score；prompt treatments 改变联合提问、信息展示和无关背景。
主要结果105 个模型 pair 中，coherence 差异的区间有 101 个不含 0，Brier 差异对应 32 个。部分无关语境让 incoherence 上升一个数量级。
复核与不确定性重复 elicitation、联合事件问题、未实现远期事件与 context arms；主要比较使用按日期聚类的 bootstrap。后续 elicitation 干预主要围绕 GPT-OSS-120B，不是每种模型都重复所有干预。
假设与解释理论基于 de Finetti coherence；实证没有需要复原的编号假设。可检验预测是事件结构和 prompt 环境影响 coherence，此表述为研究设计归纳。

这些模型报价不能交易，因此“收益”只是逻辑不一致的度量，不是可实现投资回报。Coherence 也不等于 accuracy，更不是作者证明模型拥有某种真实内部 belief。

AI agents reshape consensus formation in human groups

Lin Chen（Northeastern、Tsinghua） / Ziyi Liu（Tsinghua） / Xia Hu（Rice） / Yong Li（Tsinghua、Shanghai AI Laboratory）；四位作者的指定期刊记录均未确认

提交：2026-09-02 13:25:22 CST。可用性：全文 HTML / PDF；已读实验程序、主要结果及 supplementary methods。

背景及重要性AI 作为群体成员可能既帮助协调，也改变最终共识代表谁。共识更强不必然意味着人类意图得到更充分体现。
文章做了什么和怎么做让真人与 LLM 在同一 tangram 描述任务中互动 40 轮，操纵 agent 比例、表达坚持程度和能力。
最简单结论低比例 agent 可促进人类主导的共识；中等比例干扰协调；高比例恢复一致性，但表达内容转向 agent 主导。
  • 主实验的 AI 比例为 0%、12.5%、33.3%、50%、75%。
  • 相对纯人组，中间两档共识度降低约 23.1% 与 14.5%，不是单调的 AI 增益。
  • Shared linguistic prior 与表达 persistence 是作者检验的影响渠道。
  • 127 名人类分配至 8 个条件；不能将 40 轮视为 40 个独立群体样本。
样本、识别与机制证据
样本与 assignment中国大学招募 127 人，经英文表达、描述多样性和任务理解筛选，随机分配到 8 条件。主实验真人数依次 24、21、16、12、6；另三组各 16 人测试 adoption、persistence、较小模型。
互动与激励每个 session 共 24 个真人 / AI，40 轮匿名随机配对，同一图形、英语单句。双方完成后才看到对方描述与 similarity feedback；绩效付费，累计保底 0、最高 100 元。
主要变量all-MiniLM-L6-v2 embedding 的语义相似度；人机相互靠近方向；最终用词与语义概念的来源；感知 AI 身份及采纳意愿。
主要结果纯人组共识约 0.695；低 agent 比例提高约 8%，75% 比例约 0.725。后者的高共识伴随 agent-led content，不等价于前者的人类协调。
机制与 robustness操纵 agents 的采纳和坚持倾向，替换较小基座模型；比较词汇 / 概念 attribution、早期窗口和不同 annotation models。问卷感知与采纳关系主要是机制线索。
原文假设文中的 H1 / H2 / H3 指三类观察到的 regime，不能当作三个预注册假设。可检验经验预测为 AI 比例同时影响共识强度和归属，本句是报告归纳。

外推限制：每个条件只有一个 24 成员群组、共用一个 stimulus；真人随机分组不消除群组层面 replication 的不足。结果支持该任务中的动态机制，不能直接估计一般组织、平台社区或公众意见中的 AI 效应。

Propose to Learn, Learn to Propose: Evaluability-Aware Assistance under Bounded Rationality

Yifan Zhu（Aalto、ELLIS Finland） / Sammie Katt（Aalto、ELLIS Finland） / Samuel Kaski（Aalto、ELLIS Finland、Manchester）；三位作者指定期刊记录均未确认

提交：2026-09-02 15:48:41 CST。Under review preprint。可用性：全文 HTML / PDF；已读模型、Proposition 4.1、规划器及 simulation 结果。

背景及重要性用户拒绝 AI 建议，可能是因为不喜欢，也可能只是太难评估。把两者混为一谈，会误学偏好并妨碍后续协作。
文章做了什么和怎么做建模隐藏偏好和 evaluability burden，用 accept / reject 更新 beliefs，再规划后续建议；以受控图结构任务验证。
最简单结论眼前最易接受的建议不一定最有信息；但探索性拒绝只有在改善后续结果时才有价值。
  • Assistant 的最终目标是用户终态价值，而非即时 acceptance rate。
  • 建议离现状越远，用户评估负担在模型中越高。
  • Fisher-information 最优探测与 acceptance frontier 可以分离。
  • 高评估成本的 simulation 中，depth-2 planning 优于 myopic 比较组；未提供真人实验。
响应模型、命题与验证

Assistant 提议候选状态，用户接受则转移、拒绝则维持当前状态，双方重复互动。用户偏好参数和评估成本对 assistant 不可见；后者用 Bayes rule 更新有限网格上的 posterior，追求 horizon 末的用户价值。

P(accept) = 1 / {1 + exp[−κ(Vφ(候选状态) − Vφ(当前状态)) + α g(d)]}φ 是用户偏好，κ > 0 是 response sharpness，α ≥ 0 是评估负担强度；d 是建议距离。g(0)=0，g 非递减。这里展开了原文成本比率的简写。
P(accept) ≥ 1/2 ⇔ Vφ(候选状态) − Vφ(当前状态) ≥ (α/κ)g(d)

该 binary rule 来自带 KL cost 的 bounded-rational response，距离惩罚是额外的建模假设，并不是由 KL regularization 单独推出。Assistant 的 belief update 用此次响应的 likelihood 乘以旧 posterior 再归一化。

Proposition 4.1：固定用户参数、成本比率与 κ 为正；沿连续 proposal path，value gain 可微，增长相对 g 渐近可忽略，g 从 0 严格递增并趋于无穷。作者据此给出信息量在 0 与无穷处消失、存在 interior global maximum，且最优点落在 P(accept)<1/2 一侧的结果。它是 response model 的局部参数信息诊断，不是一个新的福利目标或已验证的人类行为定律。

规划器ProSE-Plan 使用 depth-2 lookahead，并对每种可能响应后的 posterior 继续规划。有限网格更新可以精确，有限深度 planner 不等于一般 horizon 的全局最优政策。
任务与样本Branching corridor：4 个偏好分支、公共路径长 2、分支长 4、交互 horizon 5；每条件 200 seeds，二次距离惩罚。
结果公共路径价值参数为 0.25、原文成本比率为 0.30 时，success 0.515，对比 Personalised-myopic 0.215 和 Population-myopic 0.200。
检验比较 value-greedy、threshold、myopic、belief-frozen depth-2 与 oracle；扫描成本和 task structure。收益集中在评估成本高、通用路径价值低的条件。
边界参数化模拟用户和合成任务；没有组织现场数据、用户成本估计或因果 productivity 结论。

Bonded Recourse for Smart-Contract Settlement of Compensable Agent Side Effects

Laurent Bindschaedler（MPI-SWS） / Quentin Botha（WU Vienna） / Christoph Siebenbrunner（WU Vienna）；三位作者指定期刊记录均未确认

提交：2026-09-02 07:05:43 CST。BCCA 2026 会议关联 preprint，仅计本次 arXiv v1。可用性：全文及开源实现，已读机制、evaluation 和 threats to validity。

背景及重要性跨组织 agent 行动即使获得授权，也可能留下 rollback 无法消除的损失。能否许可与谁来赔付是两件事。
文章做了什么和怎么做预先绑定作用范围、恢复方式、证据、赔付和抵押，事后按可计算程度转入自动赔付、仲裁或排除。
最简单结论抵押可以覆盖可界定的剩余损害；区块链的额外作用在于跨组织托管和挑战机制，而非自动创造更高赔付率。
  • Ex ante eligibility 与 ex post settleability 被严格分开。
  • 证据不完整或主观争议不能假装成 objective settlement。
  • 同样赔付规则的 centralized escrow 与 Recourse 在测试中损失相同。
  • 公开泄漏、不可逆转移等超出可界定赔付范围的行动不在保障内。
合约时序、资金约束与测试证据
主体与时序Operator / agent、受影响方、抵押托管合约、watchers 与 arbitrator。注册范围和规则并锁定 bond → 行动 → 恢复 → effect / recovery receipts → 提交 claim → challenge window → 赔付或仲裁。
准入与约束作用范围闭合、恢复可用、证据 schema 明确、损害有界、赔付函数可计算；抵押覆盖最大 aggregate exposure。客观赔付还需核对 receipts、恢复尝试及所有剩余后果。
分流范围外、排除项或不合格残损不能走客观赔付；受保但证据、恢复、计算或抵押检查失败的 below-cap claims 转仲裁。
已覆盖损害 = min{恢复后残损，合约赔付额，可用 bond}
未补偿损害 = max{0，恢复后残损 − 已覆盖损害}

主要结果：Postgres synthetic harness 中，相对授权加本地恢复基准，未补偿损害减少 49.8%，作者报告 95% interval 的半宽为 12.6 percentage points，来自 10-seed sweep。Centralized escrow 采用相同 payout rule，得到相同损失改善；链上安排的区别是托管、公开挑战、非合作赔付与可携带历史。

验证边界：Postgres、Git、cloud-compatible local sandboxes 共三类接口；Base Sepolia 为 testnet。它们不等于 production traffic、独立 provider attestation 或 mainnet 对抗检验。测试的 bond 为 payout cap 的 10 倍，相关故障仍需要优先顺序、按比例赔付或外部担保。论文没有证明一般 equilibrium、watcher participation 或最优保险合同。

Freemium Model for Information Provision

Igal Milchtaich（Bar-Ilan University，Economics；JET）

提交：2026-09-02 00:04:16 CST。可用性：全文 PDF，已读 setting、Propositions 1–4 与 Theorem 1。

背景及重要性信息提供者可以先改变客户所处的信息环境，再销售额外信息；免费部分可能提高而不是降低付费需求。
文章做了什么和怎么做用 posterior-dependent utility 和 concavification 刻画免费、付费两阶段 signal design，比较收入与买方福利。
最简单结论免费信息的商业收益可能来自先让客户处境变差；但普通单人 decision problem 不产生这种收益。
  • 卖方只关心信息收入，不直接关心买方最终行动。
  • 普通 decision problem 的 value of information 具有凸性，使这类 freemium 收益不成立。
  • 下游 strategic interaction 可以改变 utility 曲率并允许该机制。
  • 福利结论依赖买方不能拒收免费信息等设定，不能泛化为所有免费服务都有害。
信息设计、收益公式与适用条件
原始设定有限状态集合 Ω，prior μ0；买方对 posterior μ 的效用 u(μ) 有界。卖方选择 state-contingent signals，买方按 Bayes rule 更新。
时序与选择先免费 signal → 得到 posterior → 报价销售额外 signal → 买方决定购买 → 获得进一步信息。卖方可收取该付费信息带来的全部期望 utility gain。
约束Signal probabilities 非负、和为 1，posterior 的加权均值等于此前 belief，即 Bayes plausibility；付费购买满足 participation condition。
只卖付费信息的最优收入 = (cav u − u)(μ0)
先免费再付费的最优收入 = cav(cav u − u)(μ0)
免费信息带来的收入增量 = cav(cav u − u)(μ0) − (cav u − u)(μ0)cav 是 concavification：在定义域上支配该函数的最小凹函数。这里展开了原文中间函数的简写；一般有界 utility 下须按 supremum 理解，upper semicontinuity 等条件保障 attainment。

Propositions 1–2：第一次 concavification 给出收费 signal 的价值；再次对“额外信息的支付意愿”做 concavification，得到免费 signal 的最佳设计。没有再加新的 payoff-relevant 状态。

Propositions 3–4：免费信息给买方造成的 expected direct loss 至少等于卖方的收入增量；相对于最优 paid-only 方案，social welfare 不上升。这里明确依赖不能用 strategic ignorance 拒收免费信息；下游行动本身可能形成非凸 utility。

Theorem 1：要在某个 prior 上产生正增量，u 必须既不是凹函数，也不在删除退化 beliefs 的域上为凸函数。两状态下该条件充要，多状态下一般只是必要条件；内点不连续是原文另外给出的充分条件。两状态的最优总收入关于 prior 呈 unimodal，两个退化端点为 0。

应用边界：可用于构思信息服务的 preview 与 paid continuation，但论文没有建立 AI 模型、subscription equilibrium 或平台竞争模型；将其用于这些场景需要另行验证 utility 与拒收能力。

Pawel Struski（University of Warsaw、CCAI、GRAPE） / Jakub Swistak（Warsaw University of Technology） / Inez Okulska（CCAI） / Przemyslaw Biecek（University of Warsaw、Warsaw University of Technology、CCAI）；四位指定期刊记录均未确认
