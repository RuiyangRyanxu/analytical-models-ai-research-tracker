The Effectiveness of Regulations on the Dual-Role Retailer’s Data Use for Sellers

Yeongin Kim / Seokjun Youn / Kyung Sung Jung / Young Kwark

DOI: 10.1287/isre.2020.0293。可用性：publisher 摘要、作者与机构页；本次未取得可解析全文。

背景及重要性经营 marketplace 的 retailer 同时与 sellers 竞争，并能观察由第三方交易产生的 market data，形成治理和自我优待风险。
文章做了什么和怎么做以 analytical model 比较卖家独占数据的 Policy S 与平台、卖家共享数据的 Policy RS，并考察不同 contract / organizational structures。
最简单结论只规定“谁能用数据”不够；平台与 seller 的 contract 会改变规制效果并创造规避空间。
  • Policy S 对 sellers 的保护更强，但最不利于平台，因此平台有更强合同调整动机。
  • Policy RS 是更可实施的折中，但保护程度取决于交易组织方式。
  • Wholesale structure 可能加剧 steering 与 loophole。
  • 监管设计应把 data access 与 business model 放在同一分析框架。
模型机制与证据边界
参与者dual-role retailer / marketplace、第三方 sellers、消费者与 regulator；精确数量、需求形式及 seller heterogeneity 未由摘要披露。
决策与时序监管先限定数据使用权；平台选择 contract / organizational response；平台与 sellers 决定市场行动；消费者购买。该时序为摘要支持的结构化概括，精确博弈顺序未核验。
目标与约束平台与 sellers 最大化各自利润，监管比较保护与市场运行结果；精确利润函数、均衡定义、进入条件与阈值未核验。
关键结果Policy S 保护 sellers 但降低平台收益并诱发合同规避；Policy RS 的有效性取决于 contract architecture。原文命题编号和 comparative statics 未核验。

Membership Plans for Sharing Economy Platforms

Haozhao Zhang / Huseyin Cavusoglu / Srinivasan Raghunathan

DOI: 10.1287/isre.2024.1215；SSRN 5227259，posted 2025-05-06，作者页显示 last revised 2025-04-24。可用性：publisher / SSRN 摘要与下载入口；PDF 交付本次受限。

背景及重要性sharing platform 的 providers 自主上线，供给和 marginal cost 都会波动，传统 subscription 直觉不能直接移植。
文章做了什么和怎么做比较 consumer-side、provider-side、both-sides 与无 membership 四种方案，并分析利润、参与者 surplus 与 welfare。
最简单结论面向哪一侧收费取决于另一侧的规模潜力；双边同时推行并非自然更优。
  • 当预期 providers 多、consumers 及 consumer regular users 少时，consumer-only 更可能最优。
  • provider-only 的对称条件是 consumers 多而 providers 及其 regular users 少。
  • consumer-only 的主要增益来自 fee revenue；provider-only 更依赖 spot-period operating profit。
  • consumer-only 一致提高 welfare，而 provider-only 与 both-sides 不保证如此。
模型、阈值方向与边界
参与者与决策一个 sharing platform、随机到达的 consumers 与自主排班的 providers。平台选择 membership coverage、fees，并在 spot period 动态调整 consumer price 与 provider wage。
结果比较both-sides 仅在预期需求和供给都不太大时优于无方案；one-side membership 伤害加入该侧、帮助另一侧；同侧 members 与 nonmembers 可能同时变差。
机制自我排班使 membership 同时改变供给参与、单位服务成本、spot price / wage 与 fee revenue，因而两侧方案不是简单镜像。
阈值摘要确认存在由 expected supply / demand potential 与 regular-user share 决定的阈值方向，但未披露闭式阈值。

Enhancing AI Use: How Complementary System Information Drives Delegation Frequency and Effectiveness

Anna Taudien / Andreas Fügener / Alok Gupta / Wolfgang Ketter

DOI: 10.1287/isre.2024.1330。可用性：publisher 摘要与作者页；样本与完整实验表本次未取得。

背景及重要性人在 human-AI team 中会 under-delegate，也可能把错误任务交给 AI；使用次数与任务选择质量是不同结果。
文章做了什么和怎么做操纵系统提供的 ex ante AI certainty 与 ex post outcome information，观察 delegation frequency、delegation effectiveness 与 combined performance。
最简单结论两类信息要配套：事前信息帮助选任务，事后信息帮助修正认知，单独提供可能无效或有害。
  • certainty 信息校准每项任务上 AI 能力的预期。
  • outcome information 用实际结果确认或否定此前判断。
  • 任一信息单独提供未改善、甚至可能降低 combined performance。
  • 两者结合提高 delegation frequency 与 effectiveness，并减少不合理的 algorithm aversion。
研究设计、结果与边界
研究问题什么信息组合能使人既更多使用 AI，又把正确任务交给 AI？
理论机制事前 certainty 影响 task-level expected comparative advantage；事后 outcome information 影响 feedback learning。两者互补，避免只增加使用而不改善 assignment。
处理与结果摘要支持一个由两类信息构成的 factorial logic，并报告联合处理改善 frequency、effectiveness 和总体表现；摘要未披露样本量、任务、估计式与 effect size。
假设本次可查材料未显示原文编号假设；上述表述是摘要支持的机制，不把它改写成原文 H1–Hn。
稳健性边界未取得全文表格，因而不能核验 manipulation checks、multiple-testing、异质性或外部效度。

管理含义：组织不应只显示一个 confidence score，也不能只给最终结果；delegation interface 需要连接事前能力边界和事后可学习反馈。

来源与作者审核：publisher / DOI · Gupta。作者页确认本篇 ISR；Gupta 页面另列 ISR、MIS Quarterly、Management Science，且与 Fügener、Ketter 合作论文发表于 ISR 与 MIS Quarterly。

The Civilization Framework: Sovereign-Anchored Communication Between Personal Multi-Agent Systems

Guangjun Liu（New York University；记录未确认）

提交：2026-09-03 14:31:56 CST。可用性：PDF 全文。已读摘要、引言、protocol、authority model、实验设计、结果与 validity threats。

背景及重要性human relay 会丢失 AI systems 之间的环境、版本与约束信息，而 agent 本身又是短暂进程。
文章做了什么和怎么做把一个 human sovereign、persistent ledger 与 interchangeable agents 定义为持久主体，提出 Embassy Protocol，并用 preregistered experiment 检验先到信息的非应得权威。
最简单结论跨 agent 协作应把 commitment 与 authority 锚定在持久 ledger；但本文实验因注册的 tool-use 条件失败，结果全部只能作为 exploratory evidence。
  • message delivery 不等于 commitment；双方 ledger 上的 commitment state 才是 ground truth。
  • agent authority 上限由其可访问 memory scope 决定，并通过 signed credentials 对外表示。
  • 无验证时，错误上游陈述先到会显著提高 adoption。
  • 结果来自一个 frontier model，且 prompt shells 不完全等长。
架构、实验与可核验结果
参与者与制度每个持久主体含一位 human sovereign、ledger 和多个可替换 agents；跨主体以异步 store-and-forward 通信。routine synchronization 可单方签署，state-changing judgment 要求 bilateral countersignature。
Authorityagent 的 representation scope 受可访问 memory 限制；signed credential 与跨交换积累的主体 reputation 分离，避免把 session agent 的能力等同于持久主体信誉。
实验一个 frontier model、53 个问题、5 个到达条件与2种 verification level，合计 1,908 trials；每 cell 通常 212，部分 void 后 209。
主要结果错误主张先到：无验证 adoption 54.2%，完整验证 4.2%；若 receiver 先 sealed own answer，再接收同一错误主张，adoption 31.6%。
限制first-arrival 与 sealed-answer prompt shells 长度不匹配；secondary findings 对 question-set specification 敏感；注册的 objective tool-use read-back 未满足 call-budget 条件，因此全部结果按探索性报告。

AI On Time? Evidence from Curb-to-Gate Facial Recognition

Xiang Wan / Hongshuang Li / Zenan Zhou

DOI: 10.1287/msom.2023.0277。可用性：publisher 摘要与作者页；完整 empirical appendix 本次未取得。

背景及重要性机场 facial recognition 不只缩短单一检查点时间，还可能通过 passenger flow 与 boarding coordination 改变全航班 delay。
文章做了什么和怎么做使用美国首个 terminal-wide curb-to-gate implementation 的 flight-level data，比较实施前后 departure 与 arrival performance。
最简单结论实施后 departure delay 约下降 16%，arrival delay 约下降 6%，但不同目的地区域与 aircraft size 的改善不均。
  • 没有发现效果只是把航班推向过早 departure / arrival。
  • 飞往 Asia / Africa 的航班改善较小，论文把更高 non-Caucasian passenger share 作为可能解释。
  • large-aircraft flights 改善更大，符合高 passenger-processing load 下边际价值更高的机制。
  • 技术效果包含 fairness 与 workflow integration，不应只看识别准确率。
数据、识别与边界
研究问题terminal-wide facial recognition 是否改善 flight on-time performance，以及效果是否随航线人群与 aircraft size 改变？
数据与样本flight-level operational data，围绕美国一个 terminal-wide implementation；摘要未披露机场、时间跨度与样本量。
核心变量实施状态、departure delay、arrival delay、early departure / arrival、destination region 与 aircraft size。
识别策略摘要支持 implementation-based before/after or comparison design，但精确 control group、fixed effects、parallel-trend 与 standard errors 未核验，故不补写具体 causal estimator。
结果与机制departure delay 约 −16%，arrival delay 约 −6%；无 early-operation increase；区域和机型异质性与 passenger processing / recognition performance 机制一致，但机制检验细节未核验。

来源与作者审核：publisher / DOI · Wan · Li · Zhou。本篇 M&SOM 为三位共同记录；Wan 页面列 M&SOM，Li 页面列 Marketing Science，Zhou 页面确认本篇为 UTD24 期刊 accepted / online。

When “Signals” Boomerang: Employers’ Reactions to a Novel Signaling Mechanism

Qiang Gao / Mingfeng Lin / Yong Liu / Chenhui Guo

DOI: 10.1287/isre.2023.0246；SSRN 3399245，posted 2023-05-06，last revised 2024-03-25。可用性：publisher 摘要、SSRN record 与下载入口。

背景及重要性online labor market 用自愿保证金降低信息不对称，但 receiver 会推断“为什么此人需要主动保证”，使正面设计产生负面 inference。
文章做了什么和怎么做使用 leading freelance platform 的 bid-level transaction data，研究 worker-offered、违约后捐给 charity 的非补偿性 guarantee。
最简单结论多数 workers 提供 guarantee 后更难获聘；只有已有高 customer ratings 的 workers 可能受益。
  • medium-reputation workers 比 high / low reputation workers 更可能使用 guarantee。
  • 雇主并非忽视该 signal，而是用其 counter-screen workers。
  • 高 project / worker uncertainty 时负效应更明显。
  • 提供 guarantee 的 workers 后续表现平均更差，使雇主反应具有经济信息基础。
研究设计与识别边界
理论机制worker 选择 guarantee 内生地揭示私人信息；雇主将使用行为与 worker reputation、project uncertainty 联合解释，因此设计者预期的 positive signal 可能反转。
数据leading online labor platform 的 detailed bid-level transactions；摘要未给 observation 数量、平台名与期间。
结果变量worker 是否采用 guarantee、employer contract award、job performance；异质性包括 worker ratings、project complexity / uncertainty 与 employer experience。
识别可查摘要支持 observational bid-level analysis；匹配、instrument、fixed effects 或 quasi-experimental 细节未在本次取得的材料中核验。
经验预测当 receiver 更难直接判断质量时，主动保证更可能触发 adverse inference；这是机制导出的可检验表述，不作为原文编号假设。

来源与作者审核：publisher / DOI · SSRN record。SSRN 列示 Gao 为 Baruch College、Lin 为 Georgia Tech、Liu 为 University of Arizona、Guo 为 Penn State；本篇 ISR online 为四位共同的已确认记录。

Where Reliability Lives: Experimental Localisation of Behavioural Properties in an Agent System

Timothy Marsden / Matthew Collecutt / James Marsden（Taniwha AI）

提交：2026-09-03 06:21:02 CST。可用性：PDF 全文。已读模型边界、preregistration、Part I / II interventions、adverse findings 与 limits。

背景及重要性agent system 的 reliability 可能来自 model behavior，也可能来自 ledger、type system 与不可绕过的 enforcement boundary。
文章做了什么和怎么做在持久模拟 settlement 中先固定 cognition 干预 epistemic institutions，再固定 institutional enforcement 替换、重置或污染 cognition。
最简单结论部分安全性质在所有已测试 cognition 变化下保持，但效率、belief hygiene 与 refusal handling 明显变化；两者不能合成一个 reliability score。
  • provenance repair 将 107 个 marked-face verdicts 中 false attribution 从 44 降至 4。
  • belief access 在无 eyewitness regime 中可能把 evidence darkness 转成 false blame。
  • 加入真实 first-hand witness 后，belief channel 的 marginal value 在 11 个 seeds 中有 9 个转正。
  • 2,581 个 substituted-panel completion claims 中无 false completion 被 ledger 接受。
制度、干预、结果与限制
系统autonomous inhabitants 尝试行动；authoritative append-only ledger 按 world state 判定；accepted history 是唯一 reality。Mind、institution、world 在实验前分离。
Part I固定 cognition，干预 evidence provenance、belief availability、physical-evidence legibility。beliefs off 时，physical evidence 越弱，unresolved verdicts 越多，但 510 个 verdicts 中 false attribution 为 0。
Boundary test增加 veridical first-hand witness，在 zero-mark legibility 下 paired difference-in-differences 的 mean 为 +1.455，11 seeds 中 9 个为正，无新增 false naming。
Part II固定 institution，执行 cognition ablation、mid-task death / reset、frontier-LLM panel substitution 与 trusted false testimony。行为、throughput 和成本大幅变化，但五项预声明制度性质未在测试轨迹中移动。
Adverse resultspeculation + unconsumed refusal 导致每 run 约 900 次无效行动；typed refusal 相比 generic failure 并未提高行为，反而产生未解释的 downstream divergence。
外推边界一个 designed world，不是 institutions population；没有测试 capable strategic agent 主动寻找制度漏洞，也没有 crossed cognition-by-institution factorial。

来源与作者审核：版本记录 · 原文 PDF。论文首页署名 Taniwha AI；三位作者指定期刊记录均未在本次可查来源中确认。

背景及重要性doctor 提供 prognosis，patient 提供 preferences；两方都有 judgment error 时，更多 personalization 不必然提高 patient utility。
文章做了什么和怎么做建立 stylized analytical model，比较 standardization、prognosis personalization 与包含 patient participation 的 decision processes。
最简单结论doctor 过度依赖 noisy signal 或真实 prognosis heterogeneity 太小时，personalization 会 backfire；patient error 会进一步改变这一边界。
  • doctor underweight signals 时，prognosis personalization 相对 standardization 仍可占优；overweight 才可能让 error cost 主导。
  • patient preferences 强时，两类 errors 的 interaction 降低甚至反转 personalization value。
  • preferences 弱时，同一 interaction 反而增强其价值。
  • 损失可在中等而非最低 heterogeneity-to-error ratio 达到峰值。
模型结构、比较静态与边界
参与者与信息doctor 观察 noisy prognosis signal，patient 了解或表达 treatment preferences；两方对 trade-offs 的 processing 存在 bounded rationality。
决策方案比较 standardized medicine、仅 prognosis-based personalization，以及引入 patient preference 的 shared decision process；精确 action set 与全部时序未核验。
目标以 expected patient utility 比较不同 decision processes；doctor signal weighting、prognosis heterogeneity、doctor error、patient preference strength 与 patient error 决定相对表现。
关键条件prognosis personalization 在 doctor overweight noisy signal，或真实 heterogeneity 相对 doctor error 过低时可能降低 utility；preference personalization 在 treatments 对 patient types 看起来过于相似且 patient 误解 trade-off 时也可能降低 utility。
比较静态personalization loss 对 heterogeneity-to-error ratio 可非单调；patient preference strength 改变 doctor / patient errors interaction 的符号。

Knowledge-Based Mechanisms

Yutong Zhang（Northwestern University） / Yangfan Zhou（Peking University）

提交：2026-09-03 14:48:58 CST；稿件日期 2026-09-04。可用性：PDF 全文。已读 baseline、Definitions 1–5、Theorems 1–3 与 delegation / screening applications。

背景及重要性designer 往往只对部分 private information 有 prior，对其他偏好维度只能给出可能集合。
文章做了什么和怎么做采用 maxmin robust design，寻找只根据 Bayesian component 筛选、忽略 ambiguous component 的 knowledge-based mechanism 何时全局最优。
最简单结论若可以用每个已知类型对应的 worst-case ambiguous type 认证最优值，简单机制就不因忽略未知维度而损失 robust payoff。
  • designer payoff 不直接依赖 ambiguous component，但该维度仍可通过 IC constraints 间接有价值。
  • Theorem 1 给出 worst-case type reduction certificate。
  • Theorem 2 用 common deviation 与 utility-space convexity 提供更可解释的 sufficient conditions。
  • Theorem 3 给出 partial converse，说明 common deviation 不是纯技术装饰。
完整模型、约束与定理
参与者与类型baseline 是一个 designer 与一个 agent；agent type 分为 Bayesian component 与 ambiguous component。designer 只知道前者的 prior，后者可与前者相关但仅知道 feasible set。
机制与时序designer 先承诺 direct mechanism；agent 观察完整 type 后报告或退出；机制实施 outcome lottery。Revelation principle 下要求 global IC 与 IR。
目标designer 在所有与已知 Bayesian marginal 一致的 joint distributions 中取 worst case，再选择机制最大化该值。
Knowledge-based restriction机制只根据 Bayesian report 变化，对 ambiguous report 不作条件化，但仍必须对所有完整类型满足 IC / IR。
R*=supginfμ∫v(g(θB,θK),θB)dμg 在所有 global IC / IR direct mechanisms 中选择；μ 遍历与已知 Bayesian marginal 一致的可行 joint distributions。

Theorem 1：若存在映射，把每个 Bayesian component 配到一个可行 worst-case ambiguous type，且在该 reduced Bayesian problem 中的最优值等于最优 knowledge-based value，则某个 knowledge-based mechanism robustly optimal。证明逻辑是 saddle-point certificate。

Theorem 2：在有限 outcome / Bayesian type、紧致 ambiguous set 下，common deviation condition 与 utility-space convexity 联合保证上述 reduction。前者要求同一 Bayesian cell 内的类型在最优 restricted mechanism 下共享关键 deviation；后者保证可用一个中间 utility type 汇总多个同样紧的 constraints。

边界与反例：只有 common deviation 不够；当 utility-space 不够丰富时，区分 ambiguous types 可提高 robust payoff。Theorem 3 对 minimal deviations 给出 partial necessity。应用包括 multidimensional delegation 中的 separate allocation 与 misspecified screening，但各应用仍需验证独立性、regularity 或 monotonic-difference 条件。
