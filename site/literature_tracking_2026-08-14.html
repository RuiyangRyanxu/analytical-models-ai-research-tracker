Pay With Your Data: Optimal Data-Sharing Mechanisms for AI Services

Sameer Mehta、Chandrasekhar Manchiraju、Milind Dawande、Ganesh Janakiraman

背景及重要性AI firm 需要用户数据训练服务，但用户承担 privacy cost；关键不只是收集多少数据，还包括由谁决定分享内容和如何删减敏感部分。
文章做了什么和怎么做模型比较 manual sharing 与 algorithmic sharing：前者由用户选择数据量，后者由 firm 的算法先 redaction，再用于 machine learning training。

Farsighted Stability in Service Platform Competition

Hongqiao Chen、Pengfei Guo、Qingying Li、Yulan Wang

背景及重要性双边服务平台的 customers 和 workers 会预期其他参与者后续转移。只用 myopic joining equilibrium 可能误判平台能否共存与获利。
文章做了什么和怎么做先建立 worker-customer queueing subgame，再让两平台选择 service prices 与 wages，并用 von Neumann-Morgenstern farsightedly stable set 描述 coalition deviations。
最简单结论myopic stable outcomes 使平台利润归零；farsighted behavior 可支持双平台共存和正利润，但仍达不到合并系统效率。
  • 任何 farsightedly stable set 都是 singleton。
  • 一个 profile 为 Pareto efficient，当且仅当它自身构成 singleton farsightedly stable set。
  • 平台可在前瞻性参与者下从需求与供给两侧提取 surplus 并保持共存。
  • 竞争均衡仍低于 merged system 的效率，因此正利润不代表 social efficiency。
参与者、时序、稳定性与命题
参与者两个 service platforms、customers 与 workers；服务质量由 queueing congestion 和两侧加入决定。
时序平台选择价格与工资；customers / workers 在预期后续转移的情况下选择平台，形成 worker-customer subgame。
solution concept用 internal stability 与 external stability 定义 farsightedly stable set，并与 myopic stability 比较。

全文公式未能核验；以下仅为摘要可支持的结构化表达/推断。publisher abstract 可核验 singleton、Pareto efficiency、zero-profit myopic outcome、positive-profit coexistence 与 merged-system inefficiency；无法核验原文 queue、profit function 和 deviation path 的完整数学表达。

Sandeep Chitla、Maxime Cohen、Srikanth Jagabathula、Dmitry Mitrofanov

背景及重要性用户安装多个 app 不等于每次都把多个平台纳入 consideration set。忽略 search friction 与 platform stickiness 会高估实时价格竞争。

Keep, Customize, or Exit: Default Design and Token Pricing in LLM Reasoning Services

Ahmet Bugra Gundogan、Yigit Turkmen、Melih Bastopcu

背景及重要性reasoning tokens 同时提高 accuracy、token cost 与 latency。provider 除定价外，还能选择用户首先看到的 default budget。
文章做了什么和怎么做provider 先选 per-token price 和 default allocation；用户随后 keep、customize 或 exit。作者 backward induction 求 unique customization、default acceptance interval 和 provider equilibrium。
最简单结论只有用户重视省去 customization 的 convenience 时，default 才能改变实际 allocation；否则所有成交结果都会实现用户自己的最优 allocation。
  • 用户的 customized allocation 唯一，并随 price 与 latency sensitivity 上升而下降。
  • 给定 price，可接受 defaults 为空集或 compact interval。
  • provider 的 fixed-price 最优 default 有三种 regime：区间上端、下端或投影到内部 preferred allocation。
  • 全局问题可降为 one-dimensional price optimization，且 Stackelberg equilibrium 存在。
  • 两种 open-weight models、五个 benchmark 支持 diminishing-return accuracy-token specification。

6 · AI economy延迟索引补检decision-theoretic model

Training AI For When Humans Will Use It

Kevin A. Bryan、Joshua S. Gans

背景及重要性AI prediction 通常不是最终 action，而是被人工核验、其他模型和后续信息共同使用。因此 optimal training target 取决于 decision environment。
文章做了什么和怎么做把 AI 表示为 coverage、conditional correctness 与 query cost，并将每个 human continuation plan 写成 accuracy-coverage 平面上的 affine payoff。
最简单结论最大化 unconditional prediction accuracy 通常并非最优；verification cost 或错误损失的小变化可让 continuation plan 切换，从而使 optimal training target 跳变。
  • AI 的经济价值来自 model 与 downstream decision technology 组成的 composite experiment。
  • 便宜的 verification 倾向支持更广 coverage；昂贵 verification 倾向要求更高 selectivity。
  • 每个固定 continuation plan 对 coverage 与 unconditional accuracy 的 payoff 为 affine。
  • 多个 plans 的 value 是这些 affine payoffs 的 upper envelope，因此训练目标可出现 discontinuity。
  • heterogeneous users 与 monopoly trainer 会让统一模型偏向 marginal users，而非平均福利。
参与者、决策、目标与几何条件
参与者选择训练点的 AI model maker，以及查询 AI、核验并决定行动或 abstain 的 user。
AI primitivescoverage 是模型给出 prediction 的概率；conditional correctness 是给出 prediction 时正确的概率；两者乘积为 unconditional accuracy。
user payoff正确 action 获正收益，错误 action 产生损失，abstention 归一化为零；可支付 query 与 verification cost。
a=qp
a 为 unconditional accuracy，q 为 coverage，p 为 conditional correctness。optimal training 在技术 frontier 上选择 q 与 a，而不是只最大化 a。

时序user 决定是否 query；AI 预测或 abstain；user 选择 trust、verify、调用其他信息，最后 action 或 abstain。
continuation plans在 coverage-invariance 条件下，每个 plan 对 coverage 与 accuracy 的 payoff 为 affine。
training choice沿 accuracy-coverage frontier 选择与最优 continuation plan 的 tangency；plan 切换时训练目标可跳变。
比较静态verification 更便宜时增加 coverage 更有价值；错误损失更高且难核验时，selective prediction 更重要。
扩展分析 heterogeneous users、monopoly pricing、subscription pricing、adversarial manipulation 与 team verification。
