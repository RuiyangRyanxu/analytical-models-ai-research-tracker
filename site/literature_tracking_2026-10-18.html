Institutionalizing Trust in Data Exchange: Trust-Anchor Model of the Data Credit Guarantee Organization and Its Simulation-Based Comparison

Hiroshi Mano / Chie Sugiyama / Teruaki Hayashi

研究问题：数据交易跨 marketplace 与 data space 时，身份、权利与交易历史为何不能直接互认，独立第三方认证能否改善买卖双方收益？
模型：固定诚实／欺诈类型的卖方、根据有限交易经验参与的买方，以及提供记录共享、identity verification、交易前验证的 DCGO。数据价格固定，卖方供给无上限，参与者存在 turnover。
机制：买方在预期净收益为正时交易；欺诈可在事后以一定概率被发现，无身份核验时可换 ID 重返。DCGO 把事后记录与交易前验证组合；费用也会压低参与激励。
  • 默认模拟中，100 个卖方、200 个买方，运行 300 轮、30 个随机种子，报告最后 100 轮。DCGO 将买方净收益推近其设定的上界，身份核验与交易前验证的作用不同。
  • 卖方侧采用利润比较和模仿加入规则，不是最优加入决策；认证溢价高于费用时诚实卖方可能自愿进入。价格、认证质量、类型均未构成完整 endogenous equilibrium。
  • 研究提示跨平台信任层可能降低重复认证成本；但模拟未经现实数据 calibration，不能把局部参数结果写成一般 welfare theorem。使用权利的交易后行为也未纳入。
方法、证据边界与作者核查

时序为 turnover → 买方参与 → 随机选择未被列黑名单的卖方 → 交易前验证 → 收益 → 事后检测与记忆更新 → 假名重置。买方信息来自自身或共享记录。仿真对照为 Bilateral、完整 DCGO，以及分别取消身份核验或预验证的设计；不是数据内容真实性的无条件担保，也不是实证 causal effect。

Get In, Decide, Prove: A Merchant-Side Readiness Benchmark for Agentic Commerce

Adrian de Valois-Franklin / Alex Bogdan / Anas Ibrahim / Ibrahim Shaer / Tamaz Andguladze

研究问题：AI agent 能进入商家页面，不等于页面给出的总价、退款与交付条件足够支持购买，更不等于事后存在可核对的交易证据。
数据与方法：以 merchant、buyer mandate、agent profile 的组合为单位，区分 declared bot、declared headless browser 和 user-present browser；按 determinate / indeterminate / unknown 记录条款。
识别边界：4 家商家做完整试测，555 个网站做访问 census，330 家商家做规则评分。这是测量与描述，不是准入策略对销售、纠纷或利润的 causal effect。
  • 555 个网站中，105 个（18.9%）对两种 declared profiles 均不可读；样本来自支付处理商公开提及的客户，不是总体随机样本。
  • 330 家商家中，115 家至少在一种 profile 下达到排名所需证据覆盖；all-in total 仅在 18 家可判定。高观察分数与高证据完整性不能混用。
  • 商家侧的 bot access、条款充分性和可举证性可能成为 agentic commerce 的不同约束；权重、评分与 clearing band 尚未通过交易结果验证。
方法、证据边界与作者核查

4 家完整试测为单次观察、单个 mandate，且由一位受作者指导的 AI rater 判读；尚无独立重评。330 家样本的检查由 deterministic rules 完成，不能与四商家人工式判读混为一体。论文明确不把试测当作商家排名，不据此认定法律合规，也未证明所测缺口造成纠纷或损失。

Creative destruction: Human-AI competition in an experimental market

John J. Conlon / Peter Schwardmann

研究问题：当 AI 可独立生产时，人类是否仍靠 taste 创造更好产品，或靠消费者对 human-made 产品的内在偏好维持市场地位？
数据与设计：三项 preregistered studies 共 1,025 名美国参与者，分别为 296、180、549 人。人类用 coding agent 设计游戏，与 AI-only 产品比较；消费者支付与生产者奖金相连。
识别：随机披露生产来源及随机安排观看 AI 生产；WTP 用 incentive-compatible BDM 机制获取。它识别实验环境中的来源披露与暴露效果，不是宏观就业 displacement。
  • 在该游戏市场中，AI-only 产品优于业余和专业人类生产者设计的产品；人类生产者事前未充分预料这一优势。
  • 披露 human-designed 来源未提高消费者 WTP；告诉消费者支付归人类生产者，也未产生可确认的人类来源溢价。未发现效应不等于所有市场偏好严格为零。
  • 观看 AI 生产可改善部分产品质量指标，但未带来显著 WTP 增幅，并可能降低生产者自豪感；产出价值和工作的非货币价值需要分开。
方法、证据边界与作者核查

生产任务限制为三轮消息修改，消费为短时游戏，价格上限为小额支付。研究比较人类＋AI 与 AI-only，并不代表所有 creative work。作者明确指出难以直接外推到 superstar markets、书籍音乐或科学研究；也不能排除熟悉特定生产者等其他干预激活 human-made 偏好。

RelLedger: Relational Information Governance for LLM Agent Organizations

Junxi Huang / Wenshuo Chen / Nuoxuan Li / Kailong Wang / Meitong Shen / Yuehan Kou / Leihao Zhao / Yutao Yue / Xiucheng Wang / Nan Cheng

研究问题：agent 对关系历史的反应，是否改变相同事实能否进入组织共享记录，并影响后续 agent 的决策？
干预与变量：固定事件、信息、风险与任务，交叉改变 sender 对 event target 和 unrelated actor 的历史；另做角色互换、history rewrite、message 与 cost 干预。结果是写入／传递概率与下游检查决策。
证据设计：五个模型、302,764 条有效记录；24 个可执行 one-person-company workflows 覆盖八类模块。recipient replay 只展示 sender 写入记录，另有 forced-write 和 full-information 对照。
  • Claude 在固定 factual notice 的 conflict–friend 对比中，传递概率差为 62.22 percentage points；这不是所有任务或模型的平均效应。
  • 在可执行 workflow 中，strained history 相对 warm history 的 recipient review 差可达 −45.83 points。强制释放与完整信息对照显著缩小部分下游差异。
  • 显式 loss rules 的任务中，关系差异较小。组织治理既要检查模型回复，也要检查哪些事件被写入共享 memory，以及下游实际可见的信息。
方法、证据边界与作者核查

重复运行先在 scenario 内取平均，报告采用 10,000 次 paired scenario bootstrap；模型、场景和固定提示条件决定外推范围。文中 attribution proposition 描述已查询与缺失干预单元下线性 contrast 的可识别区间，不是关于真实企业绩效的 equilibrium theorem。本文确认了干预设计和正文结果，未把自动化组织的模拟效应外推为真实企业 causal estimate。

Behavioural Sociology of Humans and Machines

Taha Yasseri / Hao Cui / Nico Mutzner

研究问题：AI 参与交流、决策和集体行动后，人机协作中的角色、互惠、权威与责任如何被组织起来？
方法与内容：以 behavioural sociology 与 Hybrid Intelligence 为线索，综合社会感知、混合群体合作以及组织与制度安排的研究。
证据范围：本次读取 arXiv PDF，重点核验第 4–6 节的人机合作、组织权威与制度安排；综述所引原始研究的具体估计未逐篇独立复核。
  • 正文强调，应区分可观察的 machine behaviour 与人类对意图、理解和道德责任的解释；behavioural carryover 不足以证明 institutionalisation。
  • 正文区分 trust（对能力和可靠性的预期）、reliance（是否使用输出）、authority（组织赋予的 decision rights）与 legitimacy（这种安排是否被认为适当）；同一模型也可因组织规则变化而获得更大影响。
  • 这是 conceptual synthesis，不是新 causal estimate、已解 game-theoretic model 或全体组织的一般结论。
方法、证据边界与作者核查

第 5.2 节用可质疑的建议与必须说明理由才能推翻的默认分配作比较：模型能力不变，组织赋予的 authority 也会改变。第 6 节强调从 dyadic experiments 扩展到 longitudinal、multilevel 研究。本文是 narrative review，没有新的样本识别或 equilibrium；所引经验效应未逐篇重新核验，长期制度化仍是研究问题。
