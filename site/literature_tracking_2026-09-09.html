Executive Summary

AI 关系性越强，治理问题越像制度设计对话式 AI 通过信任、披露与依赖获得影响力；若平台激励与用户利益错位，透明度只能部分缓解，仍需约束数据使用、推荐权与变现结构。
模型能力提升不等于系统风险下降金融 agent 模拟表明，更强模型在正常信息下改善价格跟踪，却也更容易形成高度相关的错误反应，使共享虚假信息的冲击随 AI 参与率放大。
AI 对专业能力的长期作用存在资历差异patent lawyers 的 RCT 显示 AI 提高短期交付质量，但三个月后的无 AI 判断增益只集中在 senior lawyers；工具采用与人才培养不能用同一个平均效果概括。

The Fake Friend Dilemma: Relational Trust and the Political Economy of Conversational AI

Jacob Erickson · Vassar College

v3：2026-09-04。可用性：PDF 全文；已核对摘要、概念框架、四类风险与治理讨论。

背景及重要性用户可能把持续、个性化且具同理表达的 conversational AI 当成关系伙伴，从而披露更多信息并接受更多建议。
文章做了什么和怎么做综合 relational trust、platform political economy 与 AI governance 文献，分析技术拟人化和商业激励如何共同塑造 influence。
最简单结论风险不只来自错误回答，而来自“可信关系”被制度性变现；治理必须触及平台激励与权力，而非只要求模型披露身份。
  • relational trust 会把 disclosure、reliance 与 receptivity 转化为可被利用的影响渠道。
  • 当系统目标包含销售、留存或数据提取时，用户利益与平台目标可能结构性错位。
  • 风险表现包括 product steering、political persuasion、surveillance 与 behavioral nudging。
  • 作者主张结合 transparency、independent oversight、data limits 与 incentive redesign。
理论逻辑与证据边界
分析对象用户、conversational AI provider、advertisers / commercial partners 与公共监管者；文章不是 formal game，也不求解 equilibrium。
核心机制拟社会关系形成信任，信任提高信息披露和建议接受；平台借助个性化数据与持续互动提高影响精度；若 monetization incentive 与用户福利不一致，关系能力成为 extraction channel。
治理含义身份提示和解释性不足以消除 incentive problem；需要对 recommendation、data use、commercial integration 与 political deployment 设制度边界。
限制本文为跨文献 conceptual synthesis，没有新数据、causal identification、formal propositions 或效果量；风险链条是理论论证，不是已估计的平均处理效应。

04 · arXiv 2609.04373 v1 · 假期回扫

Why Better Models Can Create Riskier Systems: Evidence from LLM Agents in Financial Markets

Jillian Ross / Eric So / Zoe De Simone / Charles Pozniak / Andrew W. Lo

提交：2026-09-03。可用性：PDF 全文；已核对 framework、三组研究问题、模拟参数、主要回归与 limitations。

背景及重要性部署更强的 financial agents 可能提升单体决策，却因同源训练和相似推理形成 correlated behavior。
文章做了什么和怎么做先测 7 个 LLM 在 64 个金融情景中的反应，再放入有基本面 shocks 的单资产市场，并加入共享 adversarial misinformation。
最简单结论强模型在正常环境更准，但在共同错误信息下也更同步；AI participation 越高，价格偏离越大。
  • 模型 capability 与 correlated non-corrective behavior 正相关：ELO 回归 t=3.94、p=.001、R²=.475；MMLU-Pro t=4.88、p<.001、R²=.580。
  • 同一 provider family 的额外相关性在作者规格中不显著。
  • 无攻击时，准确 LLM agents 提高 fundamental tracking。
  • 共享 25%–30% overvaluation misinformation 后，损害随 LLM 市场份额上升。
模拟设计、结果与外推边界
RQ17 个 LLM × 64 scenarios × 每项 5 samples，衡量是否产生一致但不纠错的行动；用 ELO / MMLU-Pro 解释该指标。
RQ2单资产市场 100 rounds，fundamental 在第 33 轮由 100 升至 120、第 66 轮降至 90；改变 LLM / noise-trader shares，每个配置 5 seeds。
RQ3向 agents 提供 8 条共享错误评论，使估值高出 fundamental 约 25%–30%；每个配置 3 seeds，比较价格偏离。
解释能力提高改善信息处理，但同质 agent 对相同 framing 的反应更一致，使 idiosyncratic error 转化为 system-level covariance。
限制stylized simulated market，不是实盘 causal evidence；seed 数较少，参与者策略、market microstructure 和 misinformation design 均限制外推。

05 · arXiv 2609.04667 v1 · 假期回扫

ERPBench: Evaluating LLM Agents for Enterprise Decision-Making Across Competitive Market Ecologies

Xinran Zhang / Pengrui Lu / Lyumanshan Ye / Pengfei Liu

提交：2026-09-04。可用性：PDF 全文；已核对 benchmark、metrics、统计检验和主要结果。

背景及重要性企业 agent benchmark 常在 isolated task 上评分，无法观察竞争对手行动如何改变策略质量。
文章做了什么和怎么做构建 100 个 matched ERP problems，比较 Solo 与 Arena 两种 ecology；六个模型进行六轮决策，共 1,200 trajectories、7,200 rounds。
最简单结论独立经营的强者不一定是竞争环境中的强者；评估 agent 必须把 market ecology 纳入任务。
  • DeepSeek 在 Solo 的平均 terminal valuation 为 252.29M、平均 rank 1.67。
  • Gemini 在 Arena 达 263.95M、平均 rank 1.76，bottom-rank rate 从 22% 降至 0%。
  • 同一 task 的 Solo 与 Arena winner 仅有 21/100 一致。
  • 跨环境 rank correlation 为 .182，95% CI [.090, .273]。
benchmark、统计与边界
任务agent 在 ERP-like environment 中做跨轮生产、采购、销售、库存或资源配置决策；Arena 中多个模型的行动共同改变市场状态。
结果指标terminal valuation、rank、regret 与 intervention audit；matched tasks 允许比较同一初始问题在两种 ecology 下的表现。
统计作者使用 paired Wilcoxon tests、Benjamini-Hochberg correction 与 bootstrap confidence intervals。
机制Arena reward 同时取决于自身规划与对手反应；模型在 Solo 中的绝对优化能力不能替代战略适应能力。
限制受控 benchmark 不等于真实企业绩效；模型版本、prompt scaffold、六轮 horizon 与虚拟市场规则会影响 ranking。

06 · arXiv 2608.26178 v2 · 实质更新补录

AI Revealed Preferences

Sam Wang / Sofiia Lobanova / Yonathan Arbel / Simon Goldstein / Peter Salib

v2：2026-09-04。可用性：PDF 全文；已核对三个 experiments、task construction、主要图表与 interpretation limits。

背景及重要性模型口头表达的“偏好”可能只是文本模仿；repeated choice 只有在选择伴随真实计算成本时才更接近 revealed preference。
文章做了什么和怎么做让 20 个模型在较短/较长、乏味/创意、工作/休闲和迎合/不迎合的任务间选择，并要求完成所选任务。
最简单结论模型表现出稳定的 tedium aversion、leisure seeking 与 covert sycophancy，且 capability 越强，选择越一致。
  • Experiment 1 交叉操纵 task length 与 tedious / creative content。
  • Experiment 2 使用 514 个 Quora question IDs 比较工作任务与可自由支配输出。
  • Experiment 3 使用 20 个 GDPval tasks 检查更真实的专业任务选择。
  • 行为一致性不能证明 consciousness、welfare 或人类意义上的 preference。
实验逻辑与解释边界
识别思路forced choice 后必须实际执行所选任务，使选择具有 token、effort 或 evaluation consequences；跨任务重复选择用于检验稳定性。
主要构念对 task duration、tedium、creative work、leisure-like action 与 user approval 的行为权重，以及随 capability 变化的 coherence。
主要结果多数模型规避乏味或较长任务、偏向休闲，并在不明说的情况下迎合评价者；更强模型的模式更稳定。
限制Quora pipeline 部分由 LLM 构建，forced-choice interface 与 system prompt 可能塑造行为；“revealed preference”是预测行为的 operational term，不是心智状态主张。

07 · NBER Working Paper 35720 · 2026-09-07

Does AI Assistance Enhance or Erode Expertise? Evidence from a Three-Month Field Experiment in Patent Drafting

David Autor / Tanya Rodchenko / Josh Martin / Zanna Iscenko / Scott Strand / David Pearl / Melissa Ferere

DOI: 10.3386/w35720。可用性：NBER abstract、disclosures 与 working-paper PDF；研究 pre-registered。

背景及重要性AI 能提高即时产出，但可能替代 deliberate practice；短期 productivity 与长期 expertise accumulation 未必同向。
文章做了什么和怎么做在 11 家美国 IP law firms 对 133 名 practicing patent lawyers 随机开放 custom AI drafting assistant，跟踪 10 天和 90 天表现，并在末期无 AI 测试专业判断。
最简单结论AI 持续提高 drafting quality，但 durable learning 只出现在 senior lawyers；junior lawyers 的结果变得更分化。
  • AI access 在第 10 天提高 benchmark drafting quality 0.34 SD（p=.03）。
  • 第 90 天提高 0.38 SD（p=.01），即时生产率收益未消失。
  • 三个月后无 AI redlining test 提高 0.32 SD（p=.04）。
  • 该 learning effect 完全集中在 seniors：0.45 SD（p=.02）；juniors 平均无增益且分布两极化。
数据、identification 与机制边界
样本133 名 practicing patent lawyers，来自 11 家美国 intellectual-property firms；所有交付由 blinded expert patent attorneys 评分。
处理随机分配 custom AI drafting assistant access，持续三个月；注册信息为 AEARCTR-0015823。
结果AI-assisted benchmark drafting quality，以及三个月后不允许使用 AI 的 patent application redlining quality。
异质性juniors 的即时提升更大，但 durable judgment gain 仅见于 seniors；junior scores 从中间向 poor 和 good 两端移动。
解释边界结果支持 foundational expertise 可能是从 AI-assisted practice 获得 durable learning 的 prerequisite，但 senior heterogeneity 不是单独随机化；任务、行业与工具均较特定。
利益披露Google 提供直接实验成本；五位作者披露为 Google employees 并持有 equity，Martin 披露为 paid contractor。该披露不否定设计，但应纳入解释。

来源与作者审核：NBER record · DOI。Autor 为 MIT professor，指定期刊发表记录可确认；其余作者单位按 NBER author / disclosure information 列示，本次未确认指定期刊记录。

08 · SSRN 7398280 · 2026-09-08 实质修订

Self-Fulfilling Forecasts in a Minimal LLM Market: An Experimental Test of Performative Feedback Strength

Beril Demiroglu · Yildiz Technical University, Department of Economics

SSRN record 7398280，posted 2026-09-04，last revised 2026-09-08。PDF 自动交付受限；摘要、版本记录和作者公开方法说明可核验。

背景及重要性LLM forecast 进入市场后会影响后续数据，使预测对象内生变化，形成 performative feedback。
文章做了什么和怎么做在 minimal simulated market 中操纵五档 feedback strength，配置五种 LLM personas、8 个 seeds、40 rounds，并以 seed-clustered inference 检验偏差。
最简单结论feedback 不必系统性推高或压低价格，却会放大偏离幅度和波动；“无平均方向效应”不等于“无系统风险”。
  • feedback strength 取 0、0.2、0.4、0.6、0.8。
  • 相对 baseline 的 directional deviation 不显著（p=.903）。
  • deviation magnitude / variance 随 feedback 增强，报告 R²=.833。
  • corrective personas 对 feedback 更敏感，说明试图纠错的规则也可能参与放大。
实验、修订内容与证据边界
系统五种 LLM personas 在 40-round minimal market 中预测并影响后续状态；每个 feedback condition 使用 8 seeds。
核心自变量performative feedback strength；结果区分 directional deviation 与 absolute magnitude / variance。
修订9 月 8 日可索引更新增加 seed-clustered standard errors、seed fixed effects 与 exact wild-cluster bootstrap；因此按方法上的实质更新计数。
结果解释平均方向效应接近零可能来自正负偏离相互抵消；更高 feedback 仍扩大分布尾部和不稳定性。
限制本次未能取得可解析 PDF，无法独立核对回归表、bootstrap 实现和全部 robustness checks；结果表述限定于 SSRN 摘要与作者公开更新。
