Open at the Edge, Captured at the Center: llama.cpp and the Political Economy of Local AI Inference

Woohyeuk Lee、Hanlin Li、David Gray Widder · arXiv:2608.19001 v1 · 2026-08-19 23:02（北京时间）

背景及重要性开放 AI 的讨论常把 openness 当作 model weights 的属性，但真正能否在用户设备上运行，还取决于 model formats、conversion scripts、hardware backends、distribution hubs 与长期维护。
文章做了什么和怎么做作者分析 llama.cpp 在 2023 年 3 月至 2026 年 3 月的 7,681 个 merged pull requests，并结合 repository discussions、企业声明与 contributor blogs，追踪硬件支持、模型集成劳动和项目被 Hugging Face 吸收后的控制结构。
最简单结论local inference 降低 cloud dependence，却不会自动消除平台集中。执行层参与扩大时，compatibility、format defaults 与维护资源可能成为新的架构控制点。
  • 硬件支持由 CPU-first 演化为多 backend 平台，但贡献权高度不均衡。
  • model owners 对自家模型实现的贡献中位数为 0，许多兼容性劳动由 maintainers、independent contributors 与少数厂商承担。
  • Hugging Face 同时连接模型发现、转换和加载，使分发标准能够进入 local runtime 的默认路径。
  • NVIDIA 对 Vulkan 相关 PR 的份额从接近 0 上升到 2026 年约 50%，显示 vendor-neutral backend 也可能被 incumbent-specific extensions 塑造。
  • 论文建议把政策关注从开放权重扩展到 format dependency、interoperability、model-owner maintenance responsibility 与公共维护资金。

数据与样本截至 2026 年 3 月的 7,681 个 merged pull requests，配合 changed-file paths、PR titles、contributor affiliations、repository discussions、企业声明和 blogs。

Growth Without Us: Machine Consumers, Corporate Circularity, and the Decoupling of GDP from Humanity after AGI

Sahil Sharma · arXiv:2608.20231 v1 · 2026-08-21 00:26（北京时间）

背景及重要性“全面自动化后没有工资收入，谁购买产出”是常见 demand-side objection。文章把消费者理解为 demand accounting role，并问企业间投资和机器运行需求能否独立闭合经济循环。
文章做了什么和怎么做作者结合 machine-agent accumulation、von Neumann expanding economy、AK growth 与人类 ownership share，构造一个 post-AGI 条件模型；机器 agent 能执行全部任务并消耗 energy、compute、maintenance 和 upgrades。
最简单结论在 full automation 与全部关键投入可复制的强假设下，零人类消费不妨碍均衡增长；但 GDP 与人类福利可以完全脱钩，人类能否分享增长主要取决于 ownership claims 是否被持续稀释。
  • 企业间 intermediate purchases、capacity investment 与机器运行支出足以形成 demand closure，不需要人类 household demand。
  • 机器 agent 的存量由可并行的 fabrication technology 决定，不再受约 20 年人类繁衍周期约束。
  • 当全部投入可复制时，模型可约化为 AK-style growth engine，增长上限转向 energy capture 与物理约束。
  • 在 maximal-growth benchmark 中，interest rate 与 growth rate 相等；若人类持续从财富中消费，其 ownership share 会按消费率指数下降。
  • 结论依赖 full automation、可复制投入与产权结构；论文明确标注为 research candidate，不能被解读为近期预测或校准后的政策结论。

参与者与资产corporations 持有 conventional capital、machine agents 与 energy-capture capacity；人类不再是必要生产投入，只通过 financial claims 参与。
关键决策企业在三类可复制资产之间配置投资，并给机器 agent 分配 operating budget；人类决定从持有财富中消费多少。
核心假设Full automation：机器 agent 能替代所有任务中的人类劳动，包括研究、管理与进一步制造机器；所有核心投入可积累，直到 energy / thermodynamic floor 约束生效。
命题结构Proposition 1 比较人口与机器制造的 agent-growth ceiling；Proposition 2 给出企业间需求闭合；Proposition 3 加入物理增长上限；Propositions 4–5 描述 GDP、ownership 与 human welfare 的 decoupling。
均衡与阈值maximal-growth allocation 把净产出全部再投资；在人类无劳动收入、无转移支付时，ownership share 的增长率等于 asset return 减 aggregate growth 再减 human consumption rate。
证据边界这是高度条件化的理论练习，不是实证估计。1–3% 与数十至数百个百分点等量级用于 orientation，并非结构校准；institutional persistence、corporate objectives 与机器需求均是 load-bearing assumptions。
machine-agent growth = investment share / machine capital-output ratio − depreciation
human ownership-share growth = asset return − aggregate growth − human consumption rate

变量解释：第一式说明机器 agent 可被当作普通可积累资本；第二式显示人类 claim 是否存续取决于资产回报能否覆盖经济扩张和人类提款。在 maximal-growth benchmark 中 asset return 等于 aggregate growth，因此任何正消费率都会压低 ownership share。

From Agent Behaviour to Agent-Friendly Documentation: An Empirical Study of How Coding Agents Discover, Read, and Write Technical Documentation

Zhijun Gao、Jing Chen · arXiv:2608.20195 v1 · 2026-08-20 23:51（北京时间）

背景及重要性技术文档长期面向人类开发者设计，但 coding agents 已成为新的文档读者和作者。现有“agent-friendly documentation”建议多来自直觉，而非真实 workflow traces。
文章做了什么和怎么做研究结合 SWE-chat 的 557 个可解析 sessions、94,813 个 development events 与 AIDev 的 33,097 个 agentic pull requests、690,260 个 file-level records，分析文档类型、触发、相邻行为和 code-documentation order。
最简单结论agent-facing artefacts 才是主要文档界面。instruction files 与 working notes 占 60.5% 的文档互动，但读取文档是否直接促进 coding 或 validation 没有一致证据。
  • agent instruction files 与 working notes 合计占 60.5%，classical technical documentation 占 10.6%，API references 仅占 1.3%。
  • 文档读取后紧邻 code edit 的概率为 0.002；三事件窗口 unadjusted lift 为 1.05，但 stage-adjusted odds ratio 为 1.33，方向并不稳健。
  • 没有观察到明确的 documentation-based validation sequence；读取后 immediate testing 的 adjusted odds ratio 为 0.39。
  • 70.2% 的文档 consultation 是 self-initiated，仅 7.5% 是 failure-driven；在 2,034 个 failure episodes 中，文档是首个 recovery action 的比例为 5.4%。
  • 同时修改 code 与 documentation 的多 commit PR 中，code 先被修改的频率是文档先行的 4.7 倍。
研究设计、数据、核心变量、结果与 validity limits
维度全文可核验内容
研究问题coding agents 使用哪些文档、什么事件触发读取、读取后发生什么，以及 code-documentation loop 是否双向。
样本SWE-chat：559 个 stratified sampled sessions，557 个可解析；AIDev：33,097 个保留有效非 vendored 文件记录的 PRs，覆盖 690,260 个 file-by-commit rows。
核心变量15 类 documentation types、consult / produce、trigger、development stage、相邻与三事件 transition、testing / build、code-doc order、recovery outcome。
识别策略无 causal identification。主要比较来自 event sequence、cluster bootstrap 与控制 stage 的 logistic regression；两个数据集只作为互补证据，不合并样本。
原文 hypotheses无编号 hypotheses。作者把 executable documentation 能否形成可观察 validation loop 明确列为未来 intervention hypothesis，而非当前发现。
稳健性与机制检验按 session 或 repository 做 2,000 次 cluster bootstrap；报告 adjacent 与三事件窗口；检查 agent、language、task type 与 repository stars。Tier-2 文档分类未做人类标注验证，25.1% working-note share 应视为 provisional。
外部效度SWE-chat 是 opt-in telemetry 且 87% 来自单一 agent family；AIDev 偏向早期采用 agent 的 public repositories；两者不能代表 private organizational codebases。

组织含义：企业部署 coding agents 时，AGENTS.md 类 instruction files 与 agent-maintained working notes 是更直接的治理界面；但不能仅凭文档存在推断 agent 会据此验证代码，应让关键约束可执行并在 workflow 中留下可观测检查记录。
