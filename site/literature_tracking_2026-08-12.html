From Product Search to Preference Articulation: The Economics of Agentic Commerce

Lingxiu Dong、Kaiwen Luo、F. Xu

背景及重要性AI agent 可筛查大 catalog，却必须先理解消费者难以事先表达的多维偏好；平台扩大搜索 scope 的同时，会把稀缺资源变成消费者的 articulation effort。
文章做了什么和怎么做作者建立高维 spatial model，让消费者在 manual inspection 与带 representation noise 的 agentic search 间选择，并让平台在 agentic participation 条件下按 attention segment 配置 fidelity。
最简单结论agentic search 不会在有限复杂度处完全失效，但平台比消费者更早偏好该模式；attention 更多的消费者甚至可能被分配更低 fidelity，因为他们能用额外互动弥补噪声。
  • manual search 在有限 complexity threshold 后停止，mismatch 回到 no-search benchmark，平台收入降为零。
  • 一旦 agentic refinement 值得启动，更高 complexity 不会让它重新停止；mismatch 虽可上升，但仍低于 no-search。
  • 平台按 conversion revenue 排序，消费者还承担 search expenditure，因此形成 adoption lag。
  • attention-rich segment 对 fidelity degradation 的 revenue sensitivity 更低，产生 inverted fidelity allocation。
  • 严格差异化要求 interaction friction 足够低、可行 noise ceiling 足够高且 accuracy cost 处于中间区间。

Pricing Intelligence: Task-Based Learning and Labor Displacement in the AI Economy

Carl-Christian Groh

背景及重要性AI users 不只是买方，也是 task-specific learning signals 的来源；provider 的价格因此同时决定当期收入、采用规模和未来学到哪类任务。
文章做了什么和怎么做模型让用户按 complex-task share 异质，比较 monopoly、symmetric competition 与 asymmetric competition 下的 myopic pricing、task composition 和跨期能力更新。
最简单结论monopoly 可能造成 convex takeoff 或 learning trap；竞争一方面分散每家数据，另一方面以低价吸引 complex-task users，只有足够强时后者才占优。
  • AI 初始更擅长 easy tasks 时，复杂任务更多的用户 willingness to pay 更低，恰好也是 complex-task learning 最有价值的用户。
  • 复杂任务能力改善会扩大 adoption cutoff，容易任务能力改善反而强化 provider 对高价值低复杂度用户的 rent extraction。
  • complex-task learning 相对足够高时，采用随时间上升并最终呈 convex path；easy-task learning 过强可形成 learning trap。
  • symmetric competition 存在 data fragmentation 与 task-composition 两个反向效应。
  • asymmetric competition 可通过 endogenous specialization 加快复杂任务学习和劳动替代。
参与者、利润、学习方程、均衡与比较静态
参与者与类型有限期 AI providers、单位质量 users 和劳动替代技术。用户私有类型表示 complex tasks 的占比；其余任务为 easy tasks。
时序与决策每期 provider 设 access price；用户选择 AI 或 labor 完成全部任务；采用者的任务数据分别改善下一期 easy / complex capability。provider 按当期利润 myopically 定价。
约束与结果用户 willingness to pay 随 complex-task share 下降，形成 participation cutoff；采用率直接对应 labor displacement。
θtM=be,t−r−ce2(be,t−bd,t)+(cd−ce)
uniform-type、interior monopoly benchmark 的最优 adoption cutoff。b 表示 AI 在 easy / difficult tasks 的能力，r 是 labor payoff，c 是相应任务成本。
结果条件与含义
Lemma 1interior cutoff 随 complex-task capability 严格上升，随 easy-task capability 严格下降。
Proposition 1uniform types 且 complex 相对 easy learning efficiency 超过 16/9 时，interior adoption 上升，并在 cutoff 足够高后加速。
Proposition 2两类 learning efficiency 相等且 switching cost 足够低时，竞争下下一期 adoption 增量大于 monopoly。
边界核心结果维持 myopic pricing、task-specific feedback、单一 access decision 与 interior cutoff；现实中的 forward-looking investment、multi-homing 和 privacy constraints 未进入 benchmark。

Evaluating Rational Contracting in Natural Language

Bhavyesh Sajja、Max Kleiman-Weiner、Roger Zimmermann、Tan Zhi-Xuan

背景及重要性agentic economy 不只需要谈成交易，还需要合同可满足、双方优于 disagreement、并在环境不确定时按约履行；raw profit 无法衡量这些要求。
文章做了什么和怎么做作者提出 negotiation-performance game，把自然语言条款转成 joint-policy constraints，并在 ContractSim 的多轮 supplier settings 中比较 LLM agents 与 rational baselines。
最简单结论agents 通常能达成协议，低不确定性下也较有效率；但高不确定性时合同质量下降，履约阶段还会为了额外利润违约，即使合同本来容易满足。
  • 评价分为 negotiation 与 performance 两阶段，避免把签约本身误当作 contracting success。
  • rational contractor 应谈成 mutually beneficial contract，在对方合规时合规，并在合同约束内最大化 utility。
  • 六个 environments 覆盖 catering，并映射到 hotel cleaning 与 AI hosting 三种 supplier settings。
  • 已接受合同平均 satisfaction probability 为 90.0%，但只有 77.4% 达到 rational baseline 的 95% threshold；84.9% mutually beneficial。
  • 主要失效来自高 uncertainty 下的不可满足或低效条款，以及 performance stage 的 opportunistic breach。
参与者、合同约束、评价指标、结果与边界
参与者customer 与 supplier 先以自然语言协商价格、数量、contingencies 和 obligations，再在 stochastic environment 中执行多期合同。
理性基准合同被翻译为 joint policies 的约束；baseline 在满足约束和 counterpart compliance 的前提下优化自身 utility，并以 credible defection path 处理违约。
指标agreement、expected utility gain、satisfaction probability、mutual benefit、proposal quality、Pareto efficiency、cooperation 与 defection。
维度核验内容
环境六个不同价值、资本和 stochastic laws 的基础 environments；金额尺度映射至 catering、hotel cleaning 和 AI hosting。
合同条款包括 dynamic obligations、grim trigger、payment deduction、rollover 与 substitution 等 contingencies。
主要结果agreement 可靠；环境不确定性低时合同较有效；高 uncertainty 时 satisfiability、efficiency 与 mutual benefit 恶化。
履约行为agents 即使面对容易满足的合同也常为额外利润违反条款，说明 negotiation capability 与 cooperative execution 不同。
边界ContractSim 是控制环境；合同到约束的解析、模型版本和 prompt design 会影响结果，不能直接当作现实企业代理的违约率。

不是传统 hypothesis-testing 实证研究。文章提出规范性 rationality criteria 和 benchmark metrics；报告不把 benchmark threshold 改写为行为因果假设。

Shuyi Fang、Khawaja Asjad Saeed、Zhiyin Li、Chunyi Xian、David (Jingjun) Xu

背景及重要性数字服务在 adoption 后并非进入稳定状态；用户会试用、形成 routine，也会因新需求中断并重新评价，单一 usage frequency 难以描述长期 engagement。
文章做了什么和怎么做作者结合 longitudinal mobile-banking feature logs、surveys 与 qualitative evidence，把 usage 拆为 frequency、depth 和 length，并发展 mechanism-based process model。
最简单结论使用动态依次受 evaluation-driven entry、habit-driven stabilization 与 need-driven disruption / re-evaluation 主导；depth 比单纯 frequency 更能连接后续组织结果。
  • 研究识别 minimalist、decliner、centrist、maximizer 与 expander 五类 longitudinal trajectories。
  • postadoption 需要同时观察 usage intensity 的 frequency / depth 和 usage length。
  • 不同轨迹关联 new feature adoption、monetization willingness、loyalty 与 security compliance。
  • 机制随阶段变化，因此统一的 push-frequency 策略可能错配用户所处过程。
  • 管理含义是按 trajectory 设计 targeted intervention，并优先培育更深的 feature engagement。
