platform ecosystem · empirical study · 白名单期刊新 online；同题 working-paper 版本仅作内容核验，不重复计数。

背景及重要性平台 complementors 的创新不仅受平台规则影响，也取决于能否从外部引入高层技术能力。
文章做了什么和怎么做研究外聘 senior technology executives 与 startup complementor innovation 的关系，并检验高管带来的知识、网络和组织能力机制。
最简单结论外部技术高管可成为 complementor 吸收平台机会并重组创新活动的关键治理资源。
  • 研究对象直接位于 software platform ecosystems 与 complementor innovation。

  • 文章把人才流动与生态系统创新能力连接起来，为平台扶持 complementors 提供组织层面的机制。

Customers’ Multihoming Behavior in Ride-Hailing: Empirical Evidence from Uber and Lyft

platform competition · structural empirical · 白名单期刊新 online；同题 working-paper 版本仅作内容核验，不重复计数。

背景及重要性平台看到用户曾经使用两家服务，并不意味着用户每次都同时比较两家。
文章做了什么和怎么做使用纽约 162,000 名乘客、超过 140 万次行程，建立包含价格、等待时间、stickiness、Bayesian belief updating 与 consideration-set formation 的 structural model。
最简单结论只有 16.6% 的乘客曾使用两平台；即使在这群人中，两平台同时进入 consideration set 的比例也仅 43.4%。
  • 83.4% 的 riders 在样本期只使用一个平台。
  • 选择不能完全由 price 与 waiting time 解释，说明 Uber 与 Lyft 对用户而言存在差异化。
  • 更早 targeting 用户生命周期可比当前折扣策略多提高 77.56% 的 market share。
  • 针对低 search friction 用户，相对针对高 search friction 用户可多提高 24.78% 的 market share。
研究结构、证据边界与作者审核
数据NYC 2018 年 Uber/Lyft panel；约 162,000 riders、超过 140 万次 rides。
核心变量平台选择、价格、等待时间、历史体验、beliefs、consideration set 与 multihoming propensity。
识别与估计structural model 联合刻画运营属性、行为 stickiness、Bayesian learning 和 consideration-set formation，并用 counterfactual 比较 targeting policies。
管理含义折扣只有在平台进入用户 consideration set 时才有效；平台应先管理进入集合，再优化价格。

The Impact of Generative AI on Collaborative Open-Source Software Development: Evidence from GitHub Copilot

AI economy · causal empirical · 白名单期刊新 online；同题 working-paper 版本仅作内容核验，不重复计数。

背景及重要性AI 提高个体编码产出，但开放协作还要承担 review、discussion 和 integration。
文章做了什么和怎么做结合 GitHub proprietary Copilot usage data 与公开 repository data，估计 Copilot 使用对项目贡献、参与和协调的影响。
最简单结论Copilot 提高项目代码贡献，但也延长 coordination time；净效应为正且 core developers 获益更大。
  • 项目级代码贡献提高约 5.9%。
  • developer participation 提高约 3.4%，个人代码贡献提高约 2.1%。
  • coordination time 增加约 8%，并伴随更多 code discussions。
  • peripheral developers 的贡献增幅更小、协调成本增幅更大。
研究结构、证据边界与作者审核
数据GitHub proprietary Copilot usage data 与公开 OSS project data。
识别最新版摘要报告项目层面的使用比较；旧版曾使用 generalized synthetic control，最终期刊识别细节需全文复核。
机制automation/augmentation 扩大参与和产出，但新增代码提高 review 与 integration burden。
稳健性边界期刊摘要支持方向与量级；最终样本、matching 和全部 robustness 未逐表核验。

Generative Search: Evidence from a Large-Scale Field Experiment

AI application · field experiment · 白名单期刊新 online；同题 working-paper 版本仅作内容核验，不重复计数。

背景及重要性Generative search 让用户先表达 intent，再由系统辅助形成搜索词，改变了传统 keyword funnel。
文章做了什么和怎么做在美团开展 large-scale field experiment，比较 generative search 与传统搜索的购买、query、浏览和商户评估行为。
最简单结论Generative search 提高购买，并让 query 更有效、多样，减少探索性点击，把评估集中到更相关类别和商户。
  • AI-generated responses 将 interaction 上移到 problem formulation。
  • 处理组购买显著增加。
  • 用户形成更有效、更多样的 keyword queries。
  • 浏览和点击减少，但注意力更集中于相关类别与商户。
研究结构、证据边界与作者审核
研究设计美团 large-scale randomized field experiment。
结果变量购买、query effectiveness/diversity、浏览点击、类别与商户集中度。
机制生成式回答既揭示用户需求，也扩展属性 awareness，从而改善后续搜索。
边界SSRN 可核验摘要未披露本次报告可安全引用的最终样本量与全部 effect sizes。

Inflation in Reputation Systems? Newcomers, Veterans, and Socialization Within a Platform Community

platform governance · mixed-method empirical · 白名单期刊新 online；同题 working-paper 版本仅作内容核验，不重复计数。

背景及重要性评分系统的信息价值取决于用户在平台社区中的 socialization 和 reciprocity norms。
文章做了什么和怎么做exploratory mixed-method study 区分 newcomer、inflator 和 veteran 三阶段，分析 reviewer lifecycle 中 rating behavior 的演化。
最简单结论rating inflation 呈 inverted U：新用户较诚实，中期受直接互惠影响而膨胀，资深用户因对社区的 generalized reciprocity 再次更坦率。
  • Newcomers 尚未社会化，rating inflation 较低。
  • Inflators 遵循 direct reciprocity，更倾向给高分。
  • Veterans 转向 generalized reciprocity，更重视平台社区的信息质量。
  • 治理上不应把 reviewer tenure 当作单调的 reliability proxy。
研究结构、证据边界与作者审核
方法exploratory mixed-method design。
理论机制reciprocity theory；直接互惠与面向社区的一般化互惠在生命周期中交替占主导。
主要结果rating inflation 随 tenure 呈 inverted U。
治理含义声誉系统可针对中期用户设计提示、匿名化或 community-oriented interventions。

Tokenizing Loyalty Programs: The Role of Tradability

digital platform mechanism · analytical model · 白名单期刊新 online；同题 working-paper 版本仅作内容核验，不重复计数。

背景及重要性tradability 同时带来 market switch 和 strategic waiting，两者方向相反。
文章做了什么和怎么做建立两期 strategic-customer model，对比 traditional 与 tradable loyalty programs，并考察 static/dynamic pricing。
最简单结论static pricing 下 tradability 在部分参数区间占优；dynamic pricing 下传统方案利润始终更高，但可能牺牲 consumer welfare。
  • tradability 让低 valuation 用户通过交易进入市场，形成 market switch effect。
  • 可交易奖励也诱发 purchase delay effect。
  • 客户较 myopic，或 repeat-purchase discount factor 很低/较高时，tradable design 更可能占优。
  • speculators 可提高 tradability 的价值，但更有效率的 token allocation 不保证更高利润。
研究结构、证据边界与作者审核
参与者与时序firm 选择 loyalty-program design 和 pricing；strategic customers 在两期购买、累积并交易 rewards。
目标与约束firm 最大化两期利润；customers 比较即时购买、等待、复购与 token trading。
均衡结论static pricing 下两种相反机制决定最优制度；dynamic pricing 下 traditional design 的利润优势更稳健。
公式边界摘要支持机制和参数方向，最终全文公式未核验，因此不展示未经确认的阈值表达式。
