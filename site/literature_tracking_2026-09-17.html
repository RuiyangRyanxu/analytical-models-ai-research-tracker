Executive Summary

平台上的响应速度不是越快越好。eBay bargaining 数据显示 seller response time 对 buyer concession 呈 inverted-U，并因商品而异，说明平台提示和 seller decision support 应考虑 heterogeneous treatment effects。

Agent ecosystem governance 面临“增长快于审查”的问题。OpenClaw skill registry 在 91 天内接近翻倍，但多数 listing 缺乏人工反馈，security scanners 之间也存在大规模分歧。

多主体 agents 需要独立于 personal harness 的 social harness。跨 trust boundaries 的协作同时面临 honest coordination failure 与 malicious communication，单纯提升模型能力并不能解决 authority 和 accountability。

01 · M&SOM · 2026-09-16 online

A Forest Approach for Analyzing the Heterogeneous and Nonlinear Effects of Sellers’ Response Time

Guihua Wang / Wen Zhang · DOI 10.1287/msom.2023.0565

背景及重要性在线议价中，快速回复可能传递急售意愿，慢回复则可能被理解为不真诚或不负责，因此 response time 的效果可能非单调。
文章做了什么和怎么做使用 eBay best-offer platform 数据，先以 multiple-IV regression 估计平均效应，再以 multi-treatment IV forest 刻画商品层面的 nonlinear heterogeneity。
最简单结论response time 对 buyer concession 呈 inverted-U；针对商品选择最佳回复时间可明显提高 buyer concession。
  • multiple IV 设计用于处理 response time 的 endogeneity；摘要未披露具体 instruments 与 first-stage strength，因而识别细节仍需全文核验。
  • 平均效应不足以制定统一规则，因为不同商品的 treatment-response curve 差异较大。
  • 平台可把估计结果用于 seller-facing decision support，但不能把 observational prediction 直接当作跨平台 causal policy。
  • SSRN 版本显示 2026-08-26 修订；本次按白名单期刊 2026-09-16 online 状态收录并去重。

02 · arXiv 2609.17274 v1 · 新 preprint

After the Party: Governing What a Viral Agent-Skill Ecosystem Left Behind

Yunpeng Xiong / Ting Zhang

背景及重要性agent skills 以自然语言指令驱动 shell、network、credential 和 file actions，但 registry 的 popularity 与 scanner labels 未必能代表安全或持续维护。
文章做了什么和怎么做结合 OpenClaw Git history、issues、pull requests 与三个 ClawHub snapshots，分析 ecosystem growth、attention concentration、continued listing 和 scanner validity。
最简单结论registry 增长远快于人工审查，metadata 无法稳定预测持续存在，单一 scanner 也不足以承担治理。
  • observable stock 在约 91 天从 33,399 增至 65,175，增长约 95%。
  • top 10% skills 获得 46.93% downloads；77.86% listings 没有 stars 或 comments。
  • 85.06% readable skills 带有 privilege evidence，但三个 scanners 对共同覆盖的 61,990 项中有 23,702 项意见不一致。
  • 经人工 adjudication，weighted scanner sensitivity 仅为 21.67% 至 61.06%，说明治理需要透明 measurement 与 independent validation。

03 · arXiv 2609.17527 v1 · 新 preprint

Agentic Societies Need a Social Harness

Tapan Chugh / Vidushi Singh / Krish Jain / Arvind Krishnamurthy / Ratul Mahajan

背景及重要性不同 principals 的 agents 需要跨 trust boundaries 协作，目标并不完全一致，个人 agent 的 context 与 tool controls 不能覆盖 inter-agent governance。
文章做了什么和怎么做用 scheduling、stalling、deception 与 privacy-exfiltration scenarios 测试 honest 和 faulty agents，并据此提出 layered social-harness architecture。
最简单结论现有 messaging primitives 既不能保证有效协作，也不能抵御恶意通信，需要 identity、ordered communication、runtime detection 与 post-facto accountability 的组合。
  • 即使所有 agents honest，协作成功率也随参与规模和 communication design 变化；shared sessions 在部分场景显著改善结果。
  • 单个 faulty agent 可拖延流程、影响决策或利用 communication side channels 暴露 private context。
  • 所提架构从 unforgeable identity、reliable ordered communication 延伸至 personal firewalls 和 institutional adjudication。
  • 这是 proof-of-concept experiments 与 architecture proposal，并非已验证的通用治理标准。
