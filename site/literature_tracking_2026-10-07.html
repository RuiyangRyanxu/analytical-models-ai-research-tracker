The Welfare Effects of Selling Leads in a Two-Sided Marketplace

Peng Shi（USC Marshall School of Business）

背景及重要性Bark、Google Local Services、HomeAdvisor 和 Thumbtack 等平台向 service providers 出售 customer leads。Lead fee 不只影响平台收入，也会改变 providers 是否购买 lead、多少人报价以及报价水平。
文章做了什么和怎么做建立 two-sided marketplace 的 game-theoretic model，研究 customer types、provider competition、lead-purchase decisions 与 fee policy 如何共同决定 prices、quotes 和 welfare。
最简单结论提高 fee 在 quote count 不变时使报价更低，但 fee 太高会减少 quote count。按 customer type 设置 market-clearing fee，至少实现 first best 的 58.19%，并达到 welfare-optimal fees 下福利的 79.15%。
  • Conditional on the same number of quotes，fee-per-lead 上升会强化 providers 对获客成本的反应并降低 quoted prices。
  • 当 fee 高到使部分 providers 不再购买 lead，消费者收到的 quotes 减少，customer surplus 可能下降。
  • Market-clearing fee policy 在不同 customer types 上分别清算 lead market，给出可计算的 approximation guarantee。
  • 对每个成功完成的 job 补贴 provider 可以实现 first best，并避免经验丰富、拥有更便宜外部 lead sources 的 providers 退出平台。
模型结构、证据边界与作者审核
参与者Lead-selling platform、不同 customer types、决定是否购买 leads 并向消费者报价的 service providers。
决策与时序Platform 按 customer type 设置 fee-per-lead；providers 选择购买哪些 leads 并提交 quotes；customers 在收到的 quotes 中选择。
核心 trade-off更高 lead fee 可以降低 conditional quote prices，却可能通过减少 provider entry / lead purchase 降低 quote count。
政策结果Market-clearing fees 保证至少 1/(e−1)=58.19% 的 first-best welfare，并达到 welfare-optimal fees 下 welfare 的 79.15%；per-success subsidy 可实现 first best。

Personalized Recommendations Without Inducing Congestion: Mitigating Disparities in the NYC High School Match

Erica Chiang、Kenny Peng、Jon Kleinberg、Eva Tardos、Nikhil Garg（Cornell University） / Rebecca Lichtenstein、Brielle McDaniel、Kristen O'Neil、Deja Thomas、Lianna Wright（New York City Public Schools）

背景及重要性Capacity-constrained matching 中，给每位申请者单独看似有利的 recommendation 可能同时把大量 demand 引向相同项目，使原先较高的 offer likelihood 失效，并加重可选项目较少群体的不利处境。
文章做了什么和怎么做建立 congestion-aware bilevel optimize-and-simulate method，对每个项目设置 nudge capacity，再在容量约束下分配 personalized recommendations；随后在 2025-26 NYC high-school match 中进行 preregistered RCT。
最简单结论Treatment applicants 申请推荐项目的比例为 16.4%，control 为 10.5%；匹配比例为 5.6% 对 3.3%。Treatment 中没有申请者被推荐项目拒绝，说明 capacity constraint 在实际部署中保持了安全边界。
  • 模型把 recommendation 视为会改变其他参与者机会的 market intervention，而不是独立的 individual ranking。
  • 方法先用历史数据模拟 adoption 对 acceptance rate 的影响，再计算每个项目可承受的 nudge capacity。
  • Application effect 的差异为 57%（p=0.011）；match effect 为 71%（p=0.071），后者属于 suggestive evidence。
  • RCT 样本为 444 名 treatment applicants 与 822 名 control applicants；school-choice context 的效果不能直接外推到 labor 或 dating markets。
模型、实验与作者审核
参与者与约束Applicants、capacity-constrained high-school programs 与 centralized match；recommendations 只能分配给满足距离、质量与 ex ante offer-likelihood 条件的 applicant-program pairs。
核心机制Naive allocation 忽略 simultaneous adoption 引起的 equilibrium congestion；capacitated allocation 用 program-specific nudge caps 保护 acceptance rate。
IdentificationPreregistered randomized assignment；control applicants 使用其 counterfactual recommendation set 定义 comparable outcomes。
限制主要行为 effect 来自申请选择；match effect 的 p 值为 0.071。Scale-up 仍依赖 adoption、distribution shift 与 offer-likelihood model 的稳定性。

NBER Working Paper 35870 / BFI Working Paper 2026-129 · 2026-10-06 · 窗口内新 working paper

Aligning Platform and User Incentives in Social Media Age Restrictions

Leonardo Bursztyn（University of Chicago / NBER） / Rafael Jiménez-Durán（Bocconi University） / Aaron Leonard（University of Chicago） / Filip Milojević（MIT） / Christopher Roth（University of Cologne）

背景及重要性直接禁止 teens 使用 social media 要求平台主动放弃 profitable users，也要求 teens 放弃现有 social network。双方都可能规避，导致 age restriction 实际执行不足。
文章做了什么和怎么做比较 ban 与 safe-tier regime。Regulator 设置 adult-tier underage users 的 expected penalty 和 safe-tier requirements；platform 决定是否提供 safe tier 以及 enforcement 强度；teens 在 adult tier、safe tier 和退出之间选择。
最简单结论Safe tier 保留相关 network、移除受限制 features，使合规不再等同于退出。它让 platform 在较低 penalty 下先提供 safe tier，再在更高 penalty 下 enforcement，并在相关 penalty 区间提高 teen welfare。
  • Platform 不会自愿提供 safe tier 的原因是 cannibalization：从 adult tier 转移的利润损失可能超过新增用户收入。
  • Regulatory liability 先通过减少 adult-tier liability 诱导 safe-tier provision，再通过保留 displaced users 的 safe-tier revenue 提高 enforcement incentive。
  • 两种 tier 保留相同 relevant network 时，teens 的选择主要取决于 adult-only features 的 perceived value 与 evasion cost，而不再取决于放弃整个 network。
  • 在 ban 仍不触发 enforcement 的 penalty 区间，safe tier 可以提高 teen welfare；有限 interoperability friction、heterogeneous bias 与 platform competition extensions 给出结果边界。
模型结构、均衡机制与作者审核
参与者Teen users、一个 social-media platform 与 regulator；baseline 抽象 adults 和 advertisers。
信息与偏差Teens 对 adult-tier feed 存在 behavioral bias，因而 perceived utility 可以高于 true utility；safe tier 移除产生该偏差的 features。
决策Regulator 设置 expected per-user penalty 并规定 safe-tier requirements；platform 选择 product offering 与不可完全 contractible 的 enforcement；teens 选择 tier 或退出。
均衡Ban 下 penalty 低于 per-user profit 时 platform 不 enforcement。Safe tier 通过降低 liability 和保留较低 margin users，使 provision 与 enforcement 在更低 penalty 区间依次出现。
全文BFI / NBER official record 与 41 页全文已核验，包括 baseline model、propositions 和 extensions；本报告保留机制与适用条件，不重写完整代数证明。

Personal-Agent Mediated Recommendation with Cross-Platform User History

Yu Xia、Julian McAuley（University of California San Diego） / Jiangfan Zhang、Jun Xiao、Xiangjun Fan（Meta AI）

背景及重要性Personal LLM agent 可以使用 user-authorized cross-platform history，但看不到 platform 的 population evidence。直接重排可能救回 platform 漏掉的相关 items，也可能覆盖原本正确的 platform ranking。
文章做了什么和怎么做定义 platform-agent information boundary，构建 MediateRec benchmark 与 real cross-platform test；再提出 PAMO，通过 counterfactual masking 估计 personal mediation support，并在 platform-relative value floor 下分配 rank-aware advantage。
最简单结论Cross-platform history 提供了纠正 platform ranking 的新信息，但即使 proprietary LLMs 也会产生 non-negligible harmful overrides。PAMO 在 seen、unseen 和 real-platform tests 上改善 matched outcome-only RL 的 rescue-harm balance。
  • Platform 与 personal agent 拥有互补但不重叠的信息，任何一方单独排序都可能遗漏对方掌握的 signal。
  • PAMO 保持 cutoff-level advantage mass，并在不降低 average platform-relative value 的 first-order reallocations 中具有 local optimality。
  • Value floor 约束 personal intervention 不得系统性牺牲 platform ranking 所含的 population evidence。
  • Benchmark 与 real cross-platform test 支持方法比较，但不等于真实用户长期授权、privacy 或 multi-platform strategic response 的 field evidence。
模型、benchmark 与作者审核
参与者与信息Target platform 使用 local interactions 与 population patterns；personal agent 使用用户授权的 cross-platform history；两者共同决定 final top-K slate。
核心 trade-offRescue 是 agent 把 platform 低估的 relevant item 提升；harmful override 是 agent 用不充分个人证据替换 platform 的有效 population signal。
方法PAMO 用 masking 估计 cross-platform history 的 marginal support，并在 value constraint 下重新分配 rank-aware advantage。
限制实验评估 ranking outcomes，而不是用户福利、privacy cost 或 platform incentives；理论结果是给定 objective 与 local reallocation class 下的保证。

Money Creation for Crypto Space: Stablecoins or Central Bank Digital Currencies?

Jonathan Chiu（Bank of Canada） / Cyril Monnet（University of Bern / Study Center Gerzensee）

背景及重要性Stablecoins 是 blockchain transactions 的主要 settlement money。Tokenized CBDC 进入同一 crypto space 后，公共货币和私人稳定币可能竞争，也可能形成 collateral relationship。
文章做了什么和怎么做建立 competing digital monies model，比较 tokenized CBDC 的 interest rate 与 anonymity 如何改变 users、stablecoin issuers 和 social welfare。
最简单结论Moderate interest 与 high anonymity 的 CBDC 会挤出 stablecoins；high interest 与 low anonymity 时，stablecoin issuers 反而可能用 CBDC 作 collateral，扩大 stablecoin creation。
  • CBDC 和 stablecoin 的关系不是固定的 substitution；政策设计可以使二者形成 complementarity。
  • Interest 提高 CBDC 的资产吸引力，anonymity 则改变 users 直接持有 public tokenized money 的交易价值。
  • Stablecoin issuers 是否采用 CBDC collateral，决定 CBDC introduction 是缩小还是扩大 private digital money supply。
  • 论文识别引入 CBDC 在 crypto sector 中 socially optimal 的条件，但摘要不足以重建完整 threshold。
模型信息、证据边界与作者审核
参与者Tokenized CBDC issuer / central bank、stablecoin issuers 与 crypto users。
政策维度CBDC interest rate 与 anonymity；二者共同影响直接使用 CBDC 和以 CBDC collateralized stablecoins 的相对吸引力。
均衡方向Moderate-interest / high-anonymity CBDC crowd out stablecoins；high-interest / low-anonymity CBDC 可支持 stablecoin collateralization。

Navigating the Sea of Reviews: Unveiling the Effects of Introducing AI-Generated Summaries in E-Commerce

Qili Wang、Yi Su、Liangfei Qiu（University of Florida） / Runyu Chen（University of International Business and Economics）

背景及重要性AI-generated summaries 可能替代用户阅读原始 reviews，也可能降低继续贡献内容的动机。对 e-commerce platform 而言，关键问题是 summary 会挤出还是激励 user-generated content。
文章做了什么和怎么做研究 AIGS introduction 对 review volume 与 content 的影响，并用 controlled laboratory experiment 直接测量 perceived collective efficacy，检验其 mediation role。
最简单结论AIGS introduction 后 review contributions 增加。用户更相信个体评论会进入共同 product knowledge；新增 reviews 也更丰富，并补充而不是重复 summary。
  • 结果与简单 substitution prediction 相反：AI summary 没有减少 consumer reviews，反而提高 contribution volume。
  • Laboratory experiment 支持 collective efficacy 是 AIGS 影响 leaving-a-review likelihood 的 mediator。
  • Positive effect 对 well-reviewed 和 polarizing products 更强。
  • Post-AIGS reviews 更少重复 summary 已覆盖 attributes，更多讨论未覆盖 attributes，并对已覆盖内容提供更深入 elaboration。
研究设计、证据边界与作者审核
研究对象E-commerce products、阅读 AI-generated review summaries 的 consumers，以及随后贡献 reviews 的 users。
方法AIGS introduction 的 empirical analysis、controlled laboratory experiment、mediation test、moderation analysis 与 fine-grained review-content analysis。
机制AIGS 使用户看到 reviews 作为 collective knowledge 的价值，从而提高 perceived collective efficacy 与 contribution incentive。

Facade of Trust: The Impact of Adopting AI-Enhanced Profile Pictures on Trust

Sijia Ma（Tilburg University） / Chong (Alex) Wang（Peking University） / Xiaoquan (Michael) Zhang（Chinese University of Hong Kong） / Tao Lu（Southern University of Science and Technology）

背景及重要性Beauty filters 和 virtual makeup 改变 online self-presentation，但同一个 enhancement 可能同时影响自己如何信任别人，以及别人面对自己时如何行动。
文章做了什么和怎么做在 randomized trust-game experiment 中嵌入 profile-photo enhancement module，将参与者随机分配为采用 AI-enhanced photo 或使用原始照片，并区分 sender 与 receiver behavior。
最简单结论Enhanced-photo senders 发送更少金额，显示 trust 下降；enhanced-photo receivers 返回比例更高，显示 trustworthiness 上升。对手也使用 enhanced photo 时，两类影响被抵消。
  • AI-enhanced self-presentation 对 trust 和 trustworthiness 的作用不对称，不能用单一 attitude measure 概括。
  • Perceived risk 的提高解释了 sender trust 下降。
  • Counterpart enhancement 会 offset focal participant 使用 enhanced photo 的影响，说明效果取决于互动双方的 presentation state。
  • Female senders 的 trust decline 更大，male receivers 的 trustworthiness increase 更大。
实验结构、证据边界与作者审核
参与者Trust game 中的 senders 与 receivers；profile photos 分为 original 与 AI-enhanced conditions。
Randomization参与者被随机分配到采用 enhanced profile photo 的 treatment 或使用 original photo 的 control。
主要 outcomesSender transfer amount 衡量 behavioral trust；receiver return percentage 衡量 trustworthiness。
机制与 heterogeneityPerceived risk mediation；counterpart enhancement offset；sender 与 receiver 的 gender heterogeneity。

arXiv:2610.07544 v1 · submitted 2026-10-06 · 窗口内新 preprint

A Systematic Investigation of Bias in Large Language Models for Advertising Relevance

Weiwei Wang、Yinchuan Xu、Jialu Gao、Youkow Homma、Jian Jiao（Microsoft）

背景及重要性LLMs 越来越多地判断 query-ad relevance。若 advertiser name、input language 或 demographic wording 在 semantic match 不变时改变 judgment，广告平台可能同时对 users 和 advertisers 产生系统性差异。
文章做了什么和怎么做建立 counterfactual audit，使用真实 advertising logs 检查 advertiser 与 language sensitivity，并用 employment、housing、credit 的 synthetic queries 检查 demographic associations；比较 GPT-4o 与 fine-tuned Qwen-7B。
最简单结论两类模型都会因 advertiser identity 或 language 变化而改变 relevance assessment，部分 demographic comparisons 还呈现与常见 stereotypes 一致的模式。Mitigation 必须区分 company-targeting query，并考虑 training-label distribution。
  • Counterfactual construction 保持 query intent 与 ad content，单独改变被审计属性。
  • Company-name masking 对 non-company-targeting queries 更可行；当 query 本身指向公司时，masking 会删除任务相关信息。
  • Label-aware rebalancing 能降低特定 advertiser 的 relative advantage，随机减少其训练样本没有相同效果。
  • GPT-4o 的部分 mitigation experiment 只运行一次，结果不能支持稳定的 variance estimate。
数据、评估与作者审核
数据Advertiser 与 language experiments 使用真实 advertising logs；demographic audit 使用受控 synthetic queries。
OutcomesGPT-4o 输出 good / fair / bad categories；fine-tuned Qwen-7B 输出 relevance probability。
MitigationInference-time company-name masking 与 training-data label rebalancing。
