Fixed, Proportional, or Menu-based? A Study of Managed Security Service Provider Contracts

Yong Wu / Yujie Jiang / Xinxue Qu / Qianzhou Du / Zhengrui Jiang · DOI 10.1287/isre.2024.1471

背景及重要性Managed Security Service Provider 面对异质 client risk、互相依赖的 security externality，以及签约后可内生变化的 client negligence。
文章做了什么和怎么做建立 game-theoretic model，比较 fixed compensation、proportional compensation 与让 clients self-select 的 menu-based regime。
最简单结论没有一种合同恒定支配；当 security loss risk 与两种合同的 negligence gap 均适中时，menu 可同时提高 provider、clients 与 social welfare。
  • compensation structure 改变 post-adoption behavior，因此 contract choice 同时是 incentive 与 screening problem。
  • 随着 loss risk 上升，高 valuation clients 从 fixed 迁移到 proportional；若迁移降低 aggregate negligence，provider 反而会扩大 market coverage。
  • 这一 market-expansion reversal 不会出现在任一 pure regime，也不会出现在忽略 contract-dependent behavior 的 screening model。
  • private optimum 并不总等于 social optimum，文中进一步刻画需要 targeted intervention 的条件。
model structure 与边界
参与者一个 MSSP 与具有异质 valuation / risk 的潜在 clients；clients 的 negligence 产生 interdependent security externality。
决策MSSP 选择 fixed、proportional 或 menu regime 及 market coverage；clients 决定是否加入、选择合同，并在采用后选择行为。
关键机制合同迁移改变 aggregate negligence，进而反馈到网络安全、覆盖范围和 provider profit。
equilibriumpublisher abstract 支持 regime comparison、迁移方向与中间参数区间的 win-win-win 结论；全文公式与阈值未能核验，因此不重构具体 closed form。
边界结果依赖 contract-dependent negligence 与 security externality；不能直接推广到行为固定或风险独立的 client population。

But How Would AI Agents Run a Town's Economy?

背景及重要性短时 agent-society experiment 往往只显示“像人”的局部行为，无法判断 demand、wage、price 与 wealth 是否形成持续的系统传导。
文章做了什么和怎么做把 100 个有 memory 的 LLM agents 放入 Pokhara Lakeside 的封闭、money-conserving spatial economy，完成 91 次有效运行和最长 26 周模拟。
最简单结论agents 会完成经济操作，但货币基本停止流动：tourist shock 到达 business revenue 后几乎不再传到 wage 和 price，cash transfer 也大多被持有。
  • 12 倍 tourist-demand shock 将 revenue 提高 4.62 倍，其中 extensive margin 为 1.50 倍、intensive margin 为 3.07 倍。
  • wage 仅为基线的 1.03 倍且不显著；3,981 个 menu items 中只有 0.3% 曾调价。
  • 向 20 个 agents 各转移 NPR 5,000 后，311 个 pulses 仍保留 96.7%；两种估计的 marginal propensity to consume 仅 3%–4%。
  • wealth rank correlation 从 2 周的 0.964 降至 26 周的 0.752，说明短 horizon 会夸大“冻结”程度。
  • 更换底层 LLM 改变全部 measured outcomes；删除 memory 未产生可检测变化。
实验结构与 evidence boundary
系统100 个 LLM agents、真实地理、business ownership、employment、pricing、shopping 与 money-conserving ledger。
interventionstourist-demand shock、randomized cash transfer、LLM-family replacement 与 memory ablation。
验证2.44 million agent decisions；live validator 与 offline recomputation 双重核对每个 agent 的 wealth 和 signed transaction history。
解释限制这是 synthetic economy 的 system-behavior evidence，不是现实居民或真实企业的 causal estimate；LLM choice、tool design 与 prompting 都是外部有效性的组成部分。

terms.txt: A Consent and Compensation Protocol for Agentic Web Access

背景及重要性robots.txt 只能表达粗略 crawl permission，不能可靠表示 machine identity、purpose、delegation、price 或可执行责任。
文章做了什么和怎么做提出 per-path、per-purpose 的 terms.txt，并把 Web Bot Auth、signed intent、delegation token、HTTP 402 negotiation 与 signed receipt 组合成 origin-enforced exchange。
最简单结论网站可在 origin 层把 agent access 从模糊惯例转为可认证、可计价和可审计的 transaction，但法律执行仍须与技术执行区分。
  • protocol 的治理对象不是“AI 是否能访问网页”这一单一 binary choice，而是 identity、purpose、scope、price 与 downstream delegation。
  • signed receipts 为 dispute 与 audit 留下 machine-verifiable trace。
  • dependency-free implementation 在单 vCPU 上每个 request 增加约 0.20–0.65 ms。
  • performance benchmark 只说明 middleware overhead，不证明 adoption、interoperability 或 publisher bargaining outcome。

04 · arXiv 2609.10856 v1 · 新 listing

Following the Preference, Missing the Optimum: Compliance Without Optimization in AI Housing Recommendation

背景及重要性既有 housing audits 能检测 identity steering，却难以量化 recommender 漏掉更好选项所造成的 opportunity cost。
文章做了什么和怎么做为 150 个 NYC synthetic renter scenarios 各构造 120 条真实 listing 的完整候选池，计算 feasible set 与 Pareto frontier，并运行 9,945 次模型调用。
最简单结论hard-constraint compliance 接近完美，但 39.0% recommendations 被同一池中的另一套房源在 rent、commute 和 bedrooms 上严格 dominate。
  • constraint violation 仅 1.8%，远低于 random-selection floor 66.6%，说明模型理解限制条件并非主要瓶颈。
  • dominated recommendation 的替代房源中位数每月便宜 900 美元且 commute 少 3.5 分钟。
  • 改变一句 preference 会让推荐租金向正确方向移动 646 美元，但明确的 lexicographic instruction 仍未改善 optimization。
  • candidate set 从 10 增到 80 时，最便宜房源出现率从 93.7% 降到 53.5%。
  • fixed-pool identity contrasts 几乎全为 null，但这不能外推到 open-ended search。
research design 与边界
ground truth已枚举 listing pool、已知 rent / bedrooms、由 GTFS 计算 commute，并精确构造 feasible set 与 Pareto frontier。
outcome无需指定 utility function 的 strict-dominance rate，以及相对 oracle 的 rent 与 commute gaps。
比较三种模型、两家 vendors；包含 preference manipulation、lexicographic instruction、pool density 与 candidate-set-size arms。
边界结论识别的是 fixed candidate set 内的 re-ranking performance；不等于开放网络搜索、真实申请获批或 neighborhood steering 的整体表现。

05 · arXiv 2609.11373 v1 · 新 listing · accepted at ICWSM 2027

Characterizing Bluesky Content Moderation Service: From Automation of Service to Landscape of Harms

背景及重要性major platforms 的 moderation pipeline 通常不透明，外部研究难以同时观察 label timing、automation 和漏检。
文章做了什么和怎么做利用 Bluesky default moderation service 的 2025 public logs，对 1,060 万 labels 做时序与内容分析，并加入人工 annotation study。
最简单结论系统对明确内容自动且快速，对 nuanced / high-stakes labels 更多依赖人工；precision 较高但 recall 很低。
  • sexual 与 graphic labels 常在数秒内自动施加，nuanced labels 则可能耗时数小时或数日。
  • 人工样本中的 precision 为 0.837、recall 为 0.222；annotators 找到的 harmful content 是系统的 4.5 倍。
  • unsupervised clustering 显示已识别 harms 覆盖 protected groups hostility、sexual 与 graphic content。
  • 公开 logs 提高可审计性，但 manual coding protocol、sampling 与平台特有 taxonomy 仍限制跨平台外推。

Buyer Artificial Intelligence-Enabled Environmental Governance and Supplier Environmental Controversies: An Organizational Information Processing and Signaling Perspective

背景及重要性buyer 的 AI governance 可能跨越 firm boundary，提高对海外 suppliers 的监测与信息处理能力，但这种 spillover 尚缺少系统证据。
文章做了什么和怎么做从 U.S.-listed firms 的 10-K 构造 buyer AI-enabled environmental governance measure，并将 FactSet relationships、RepRisk 与 country institutions 合并为 supplier-year panel。
最简单结论较高 buyer-AI exposure 与次年较少 supplier environmental controversies 相关，且在 AI readiness 和 regulatory quality 更高的国家关联更强。
  • 样本为 2020–2024 年、41 个国家的 2,505 个 foreign suppliers，采用 multidimensional fixed effects 与 firm-clustered standard errors。
  • 理论机制结合 organizational information processing 与 signaling：AI 同时提高信息处理能力，并向 supplier 传递更强 oversight 信号。
  • 作者报告 alternative measures、samples、estimators 与 endogeneity-mitigation checks。
  • 核心结果仍是 observational association；text-derived exposure 和未观测 buyer governance capability 可能限制 causal interpretation。
identification 与边界
unitsupplier-year，unbalanced panel。
treatment proxybuyer 10-K 中 sentence-level text analysis 生成的 AI-enabled environmental governance exposure。
outcome下一年度 supplier environmental controversies。
moderatorssupplier-country AI readiness 与 regulatory quality。
限制fixed effects 和 robustness checks 不能自动排除 time-varying omitted variables 或 disclosure endogeneity；报告不将该关联写成已证实的 causal effect。

07 · arXiv 2609.11146 v1 · 新 listing

The Oligarch Barely Steers Model Collapse in Multi-Model Ecosystems

背景及重要性AI-generated text 回流 training corpora 会导致 model collapse；现实 provider market 高度集中，因此需要区分 concentration effect 与 supplier-composition effect。
文章做了什么和怎么做让 13 个 open 1–4B models 组成 3–13 个成员的 ecosystems，并注入最高 90% share 的 dominant provider；每代按 share 混合输出并从 clean base weights 重新训练。
最简单结论在五代实验范围内，market-share concentration 几乎不决定 collapse 的速度或终点；更关键的是哪些 models 供应数据以及它们自身的 susceptibility。
  • collapse 本身很严重：median perplexity 从 97 升到 699。
  • 保持 shares 不变而替换三成员 ecosystem 的组成，可使五代 drift 相差 2.8 倍。
  • share-weighted susceptibility index 解释 19 个 arms 中 68% 的速度差异。
  • 将一半 pool 换成人类文本约减半 drift，但不改变方向。
  • 这是 controlled small-model ecosystem；不能据此断言 frontier commercial models 的 concentration 无关紧要。

Multilisting for Horizontally Differentiated Services: Implications for Throughput and Social Welfare

Zhou Chen / Yichuan Ding / Luyi Yang · DOI 10.1287/opre.2024.1130

背景及重要性healthcare、public housing 与 vaccination systems 允许用户进入多个 wait lists，可扩大 access，但也可能制造重复排队和 congestion。
文章做了什么和怎么做建立 horizontally differentiated service providers 的 analytical model，比较 multilisting、single-listing 与 pooling 下的 join、choice、throughput 和 welfare。
最简单结论multilisting 至少达到另外两种设计的 throughput，并优于 pooling 的 welfare；但相对 single-listing，额外 participation 可能因 congestion 降低 welfare。
  • 更多 choice 稳定提高 participation 和 throughput，但 throughput improvement 不是 welfare guarantee。
  • welfare-maximizing allocation 可能对 otherwise identical providers 采取 asymmetric treatment。
  • nonnegative asymmetric prices 可把 customers 引导到 socially efficient choices。
  • publisher 可见摘要未提供完整 utility、queue discipline 与 closed-form thresholds；本报告不补造公式。
model structure 与边界
参与者horizontally differentiated providers 与可选择一个、多条或 pooled wait list 的 customers。
decisionscustomers 决定是否进入及进入哪些 queues，并在 service available 时选择 preferred provider 或退出。
outcomesparticipation、throughput、congestion 与 social welfare。
comparisonsmultilisting 对 single-listing / pooling 的 throughput dominance，以及对 welfare 的条件性排序。
边界结果依赖 capacity constraints、horizontal differentiation 与 queueing structure；不应直接推广到无 congestion 或可同时消费多家服务的 market。
