Tempting the Agent: The Economics of Reputation without Persistent Identity in AI Agent Markets

Federico Gatta（Scuola Normale Superiore；记录未确认） / Manuel Naviglio（Scuola Normale Superiore；记录未确认） / Francesco Tarantelli（University of Bologna；PhD: Pisa；记录未确认）

提交：2026-09-02 23:47:12 CST。可用性：HTML / PDF 全文。已读状态、Bellman equation、monotonicity 命题及受限 quality comparative statics。

背景及重要性AI agent 可以重置身份时，持续经营的声誉收益与一次性违规收益需要同时比较。
文章做了什么和怎么做建立无限期动态控制模型，让 agent 选择诚实及质量，或偏离后进入重置状态，并考察 staking 成本。
最简单结论更高声誉不一定更能约束偏离；它也可能放大可攫取的交易量。
  • 声誉分数与历史深度是两个状态，不应合并成一个 rating。
  • 业务量是状态的 reduced-form 函数，论文不是完整多方市场 equilibrium。
  • Staking 同时减少偏离净收益并提高诚实经营成本。
  • 质量对状态和抵押率的单调性只在额外限制下成立。
动态模型与适用条件
状态与行动F、M 均在 [0,1]：分别表示声誉分数与历史深度。每期先选 honest / deviate；honest 时选 q ∈ [0,1]。交易量 v(F,M) 随两个状态上升，具有原文规定的凹性和互补性。
时序观察 F、M → 选择行为与质量 → 获得当期收益 → 诚实时更新声誉，偏离时进入 R(F,M) → 下一期。贴现因子 β ∈ (0,1)。
参数f 是单位业务收入；θ 是偏离攫取系数；κS 是 staking 强度；κR 是重置成本；cₒ 为占用资金的 opportunity cost，c(q) 为质量成本。
诚实当期收益：f v(F,M) − cₒ(κS v(F,M)) − c(q)
偏离当期收益：(θ − κS)v(F,M) − κR
诚实后状态：((1 − λ)F + λs(q), (1 − ρ)M + ρσ(F,M))λ、ρ 是更新速率；s(q) 是质量对应的评分；σ(F,M) 决定历史深度更新。偏离后状态由 R 给出，其结构属于模型假设。

Bellman 比较：V(F,M) 是以下两项的最大值：偏离当期收益加 βV(R(F,M))；以及对 q ∈ [0,1] 最大化的“诚实当期收益 + βV(诚实后状态)”。因此，偏离判断包含未来状态价值，不可用当期收益阈值代替。

Proposition 4.1：在 A1–A4 的连续性、单调性与成本 / 转移条件下，存在唯一连续 value function，随 F、M 不减，随 staking 强度不增。这里报告的是原文条件性结论，不是对任意重置规则的保证。

声誉何时放大 temptation？

在 λ = ρ = 0、固定 reset 状态且 cₒ(z) = az 的基准下，原文的 temptation 随业务量变化的方向由下式符号决定：

(θ − κS)(1 − β) − f + aκS

为正时，业务量上升强化 temptation；为负时方向相反。此符号刻画斜率，不等于某个具体状态已发生最优偏离。小幅正更新率下的延续结论需要严格裕度及状态分离条件，不能无条件外推到整个状态空间。

Quality comparative statics：第 7 节另加 always-honest、σ 只依赖 M、线性 opportunity cost 及 a < f 等限制。在该 regime 内，最优 q 随 F 下降、随 M 上升、随 κS 下降。它不是包含最优偏离选择时的全局比较静态。

含义：平台不能只依赖“声誉更高就更可信”；还要关注状态如何扩大 agent 的交易容量、身份重置损失，以及 staking 对正常服务质量的抑制。

Bundling Complements

Weijie Zhong（Stanford GSB；AER、Econometrica、REStud）

v2：2026-09-03 23:30:52 CST；v1 为 2026 年 7 月，已在历史报告出现。可用性：两个版本 HTML / PDF。已对照定义、主要命题与相关证明结构。

背景及重要性核心产品与 add-ons 的互补性可能支持组合销售，但“互补更强”本身不是所有菜单简化的充分条件。
文章做了什么和怎么做在多维私人估值的 monopoly screening 中，以最优传输证书比较有限 core 菜单和所有可行机制。
最简单结论足够强的互补性可以保证 core-peripheral bundling 最优，但需要菜单覆盖与严格分布条件。
  • v2 明确区分 weak 与 strict core regularity，并重写部分 unbundling 与证明结构。
  • 低维或受限菜单中的最优，必须额外排除其他 bundles 和 lotteries 的偏离。
  • 有限阈值依赖 inclusivity；遗漏高单项估值区域可能无法靠提高互补性补救。
  • 显式上界是 sufficient certificate，不等于真实最小阈值。
模型、全局保证与版本变化
参与者与信息一个 monopoly seller，N 个不可分商品，一个具有私人估值向量 x 的 buyer；x 来自原文规定的 box domain 与平滑密度。固定 core 集合 C。
时序Seller 事前公布 bundle lottery 与 payment 菜单 → buyer 知道自身 x，选择 surplus 最大的选项或退出 → 分配并付款。Indifference 按 seller-favorable 规则处理。
目标与约束最大化期望付款；每个 lottery 的概率非负并满足概率可行性；所有类型、所有报告之间的 global IC；IR 至少允许零价格空 bundle。不是只检验局部 FOC。
若 C ⊆ B：vB(x) = α ∑i∈B xi
若 C ⊈ B：vB(x) = ∑i∈B xi
选项 ℓ 的 buyer surplus：∑B σℓ(B)vB(x) − pℓα > 1 表示包含完整 core 的互补溢价；α = 1 是 additive benchmark。σ 为 bundle lottery，p 为付款。

Theorem 2 的条件：候选有限 core 菜单必须在受限类中最优，并满足 inclusivity 与 strict core regularity，以及全文的密度 / radial-score 条件。Inclusivity 约束高单项估值的 top faces 不被排除。Strict core regularity 要求相应 stochastic-dominance order 在以共同正概率部分拆开 core 时仍保持。

若已认证统一 unbundling slack ε > 0，则 α ≥ 1/ε 给出充分阈值。

该保证是对完整机制集合的最优性证书；ε 需要由具体 menu–density pair 验证，不能仅由“产品互补”推定。Theorem 4 给出 inclusivity 失败时的障碍；纯 bundling 情形又与 bundle-value distribution 的 Myersonian regularity 联系起来。

两商品 iid uniform 示例：α < 1/2 时有 separate-sales 证书；纯 bundling 在 α ≥ (9 + 4√6)/15 ≈ 1.253 时获得显式充分证书。原文未声称该上界 sharp；中间区间没有被这两个证书完整解决，α = 1 的已知 mixed-bundling 结果只是其中一个切片。

v2 实质变化：对照 v1 与 v2，regularity 的 weak / strict 区分、partial-unbundling 稳健性条件及相应 coupling / saddle-point 证明结构有重写。摘要基本一致，不能把本文的原始 bundling 思路当作 9 月首次提出。

应用边界：可用于 core product 与 AI add-ons 的菜单设计，但没有内生创新、平台竞争或治理权投资；这些是未来建模方向，不是本文结论。

Data Market Design through Deep Learning

Sai Srivatsa Ravindranath（Harvard SEAS；记录未确认） / Yanchen Jiang（Google Research；论文署名 Harvard SEAS；记录未确认） / David C. Parkes（Harvard SEAS；Management Science）

v2：2026-09-03 03:45:54 CST；v1：2023-10-31，关联 NeurIPS 2023。可用性：v1 / v2 HTML / PDF。已读设定、新增统计保证及 benchmark 相关段落。

背景及重要性卖给一个买方的信息会影响竞争对手，数据市场的 IC 与 participation 不能只看单个买家的信息价值。
文章做了什么和怎么做学习信息披露与收费机制，用 regret 约束限制误报与不服从，并在修订稿中补充泛化和独立测试保证。
最简单结论神经网络可以帮助寻找机制，但有限样本、局部偏离搜索的低 regret 不等于全局 incentive compatibility。
  • v2 新增 generalization、network-capacity、hold-out regret 结果及 benchmark 材料。
  • 买方同时可能 misreport 和 disobey，不能把两种偏离割裂核查。
  • Opt-out payoff 受卖方向其他买方披露信息的影响。
  • 统计证书需要其有界性、独立样本与 exact best-response 条件。
市场设定、机制学习与修订内容

证书边界：Generalization 需要 bounded values / payments 与机制类复杂度条件；capacity 结果针对相应 bounded-activation 类，不能不经检查就套用于实际 LeakyReLU 网络。Hold-out regret 界要求独立测试集与 exact global best-response regret；gradient search 得到的小 regret 可能低估可获利偏离。

结果与含义：数值实验比较 learned revenue、regret 和解析 / 离散 benchmark，部分情形仍有差距。它说明 computational search 可辅助信息市场设计，而非证明训练网络在任意环境都 revenue-optimal 或 BIC。数据市场研究需要把 disclosure externality 与参与约束一并建模。

Otter: A Provably MEV-Resilient Automated Market Maker via Surplus Redistribution

Elaine Shi（Carnegie Mellon、Oblivious Labs；记录未确认） / Mengqian Zhang（Carnegie Mellon；PhD: Shanghai Jiao Tong；记录未确认） / Hao Chung（LayerZero Labs；记录未确认） / Yuhao Li（Columbia；记录未确认）

提交：2026-09-03 15:31:19 CST。可用性：HTML / PDF。已读交易模型、机制构造、Theorem 15 与 censorship / capacity 限制。

背景及重要性Block builder 可以排序、插入或影响交易，市场设计必须同时限制用户与掌握交易入口的中介。
文章做了什么和怎么做构造 AMM 批量清算规则，结合初始 spot price、残余单边 VCG 与向 community 分配 surplus。
最简单结论交易费用和剩余收益流向改变操纵激励，但防操纵保证依赖明确的交易纳入与容量假设。
  • 同时考虑用户的价值 / 数量误报、Sybil 与 builder 自有交易。
  • Surplus 不直接返还给当前 batch 参与者或 builder。
  • Welfare 最优性只针对原文定义的 deterministic natural mechanism 类。
  • 可审查交易、区块拥堵时存在不同的不可能性约束。
交易模型、机制与理论保证
参与者与信息两资产 X / Y 的 AMM pool、具有私人 reservation value 与最大出售数量的用户、可排序和插入交易的 block builder。用户可提交有限多身份与相反方向订单。
曲线与可行性F(y) 表示 pool 净收入 y 单位 Y 时净付出的 X。原文要求连续、严格递增、凹、F(0)=0，以及导数和边界条件；储备与交易不得违反可行域。
时序Pool 初始储备给定 → 用户报单 → builder 组织 batch → 规则筛选和清算 → 资产及 surplus 转移。保证部分以 censorship resilience / uncongested block 为前提。
Constant-product 例子：F(y) = x0 − x0y0/(y0 + y)
出售 Y 的单向可行订单收益：x − vy，0 ≤ y ≤ qx、y 为收到 X 与售出 Y，v 为 reservation value，q 为最大出售量；完整模型另约束净交易方向、相反订单与 infeasible outcome，不能仅用此单向表达覆盖所有攻击。

清算机制：先按初始 spot price 排除不合格订单，minority side 按该价格全部执行；dominant side 的残余需求通过结合 spot-price 线性段与 AMM 曲线的单边 VCG 清算。产生的剩余收益分给 community，而不是根据本 batch 结果直接奖励 builder 或参与者。

Theorem 15：在原文模型条件下，Otter 满足 user incentive compatibility、builder incentive compatibility、individual rationality、budget feasibility 与 no subsidy。Builder 的自有交易收益也纳入偏离分析；不是只排除简单重排。

效率与边界：Welfare 保证针对 eligible users 与 deterministic natural mechanisms；natural 类要求排除不合格交易、避免与规定价格方向相反的交易。它不是对所有交易者、所有随机机制的无条件最优性。

Capacity / censorship：有限区块容量且 builder 能删除交易时，原文给出非平凡匿名 IC 机制的障碍；另讨论 outcome-dependent builder fee 必须消失的必要性。这里不能推断所有固定支付也被禁止。

平台含义：掌握交易入口的中介如何获酬，是机制能否抗操纵的一部分。论文提供理论构造，不是生产部署、吞吐量或实际用户福利的实证证明。
