The Delegation Dilemma: Economies of Scale, Accountability, and Polycentric Governance

Arin Mukhopadhyay / Aris Filos-Ratsikas / Panayiotis Danassis

研究问题：组织或平台把决策集中给代理中心后，规模经济何时与成员通过退出约束中心的 accountability 冲突？
参与者与时序：成员独立行动或加入中心，分摊组织成本；中心可利用委托权攫取利益。成员受到 L 轮 lock-in，未来以 δ 折现，被利用后在下一次退出机会以 α 概率离开。
信息与约束：中心比较当期利用收益与未来成员留存价值；continuation 中退出者不被替补。参与约束给出最小可行规模，individual exit 对中心的约束给出可问责规模上界。
  • 在论文假设下，大组织的平均成本更低，但单个成员的边际留存价值下降，退出威胁因而变弱；成本效率不自动保证 accountability。
  • 当最小参与规模超过单中心的可问责上界，而分散委托仍可行时，需要多个中心。该结论有参数与 continuation 条件，并非所有平台都应采取 polycentric governance。
  • 30 个 agents、5 组 matched simulations 展示集中、利用、退出及组织重组；模拟不能证明收敛到稳定 polycentric equilibrium。
方法、证据边界与作者核查

本次读取正文模型、激励约束与模拟设计。中心单目标 deviation 的约束在文中给定条件下扩展到可加的多成员利用；没有把固定 continuation 约束提升为所有 off-path histories 下的一般 SPNE 分类。替补成员、collective exit、法律惩罚和其他制裁可能改变约束。报告不复写未逐式核验的公式。

Do Rollups Self-Organize? Multi-Agent Reinforcement Learning in the EIP-4844 Blob Fee Market

Alessio Brini

研究问题：Ethereum rollups 独立学习何时提交交易数据，能否通过平台 fee rule 自发接近容量目标？
参与者与决策：各 rollup 在 post 与 wait 间选择，权衡 posting cost 和 delay cost；提交量共同改变下一期费用。主要实验为 5 个 rollups、5 个 seeds。
环境与信息：用 post-Dencun 的 18 个 rollups 数据 calibration，采用历史 Dencun 参数：每 block 目标 3 blobs、上限 6；L1 gas 外生，builder 为规则式 pass-through。
  • 在 100 倍基准需求的主实验中，平均供给为 3.32±0.01；informed myopic rule 也达到 3.29，不能把接近目标完全归因于 RL。
  • 10–200 倍需求范围内供给接近目标；500 倍需求下约为 4.29，费用逼近仿真数值上界。该上界不是协议物理 hard limit。
  • 近乎无成本的 calldata outside option 使费用降低约一个数量级，而吞吐量仍近目标；这依赖历史费用结构与该 outside option 假设。
方法、证据边界与作者核查

这是校准仿真，不是 fee rule 的现实 causal estimate，也没有一般 Nash equilibrium 或 multi-agent RL convergence theorem。论文明确其配置不等于当前主网参数；后续协议升级、calldata 成本和 reserve price 限制结论外推。本次核验模型、实验设定、结果和 limitations。

Provable Authority: A Protocol for Verifiable Authority Resolution and Control Across Human, Organizational, and Agentic Transactions

Jeremy Blackburn / Tim Hines / Matthew Koepp / Russell Lessard / Jason Patrick

研究问题：签名或身份认证证明谁发出指令，但如何证明一个 agent 此刻有权代表组织执行这笔具体交易？
机制：版本化 Authority Resolution Pactvera 记录授权范围、证据和撤销状态；确定性 predicates 输出 reason codes，再按组织政策决定执行、拒绝或升级人工审批。
执行约束：commit 绑定具体 canonical transaction digest；通过 atomic budget reservation、短效且单次使用的 Execution Authorization Credential 与执行端校验，减少授权和实际交易不一致。
  • 研究把 identity、organizational authority 和实际 execution 分开；agent 的能力与 API access 不等于组织赋予其交易权。
  • bounded-freshness 检查、撤销检查、人工审批和 append-only terminal evidence 构成可追溯控制链，但仍依赖原始证据与执行端正确落实。
  • 这是协议与架构设计，未报告证明商业绩效改善的 field experiment、equilibrium 或 welfare theorem；不据此认定其在所有司法环境中法律充分。

本次读取授权对象、判定流程、交易绑定、预算保留与 credential consumption 等正文部分。文稿日期为 9 月 1 日，arXiv v1 提交为 10 月 16 日；按后者作为本次可核验版本日期。没有生产部署效果或 end-to-end 测试证据可供本次确认。

Credit Markets with New Screening Technologies

Maryam Farboodi / Péter Kondor / Pablo Kurlat

研究问题：AI／数据 screening 的平均准确率相同，但不同机构犯错的相关性不同，信用市场的分层、利率与技术外部性是否因此不同？
参与者与时序：risk-neutral lenders 在 lending 前付成本选择 screening precision，随后选择利率及 selective／non-selective lending。借款人先寻求最低利率，被拒或 rationed 后进入更高利率市场；下一期 good 类型偿还、bad 类型 default。
信息与均衡：借款人 repayment type 与 opacity 不可直接观察；lenders 的单位资本和未使用资本收益约束给定。free entry、利润最大化、zero profit 与 market clearing 共同决定 precision 分布、利率和剩余 pool。
  • Independent 与 nested signals 具有相同 marginal accuracy，但误差相关结构不同。前者的 cream-skimming 恶化剩余 pool；后者的较高精度错误集合嵌套，可产生不同的 pool-cleansing 外部性。
  • 正文构造 nested 情形的市场分层：低利率 pooling、中间 screening-intensive 区间，以及可能存在的高利率 non-selective lending；第三段不是无条件存在。
  • 更低技术成本不保证所有借款人受益，且平均利率还受借款规模和构成变化影响。论文提供理论机制，不是 AI 信贷部署的 causal estimate。

How language model agents reshape price competition

Martin Bichler / Philip Hierhager / Kassian Köck / Fabian Pieroth

研究问题：LLM pricing agent 的决策接口与反馈信息，如何改变与传统学习算法的竞争，以及 LLM 之间的价格动态？
市场与决策：repeated homogeneous Bertrand 环境、离散价格 grid。比较每期选 point price 且读取原始竞争历史，和每 25 期基于收益摘要选价格分布的接口；竞争基准与 stage Nash 取决于有限 grid。
信息与比较：控制对手为 Exp3、BM-RM、PPO、UCB 等 learners，并做 self-play 和混合接口。主要复制比较使用 2,000 期、10 个 independent seeds。
  • D-S-25 在指定基准 learners 生成的价格路径中取得约 71–72% industry profit；full-information benchmarks 下优势减弱。该指标不是总 welfare 或消费者收益。
  • point-price／原始 rival history 的 self-play 可维持高于竞争基准的价格；distribution／periodic summary 接口更接近竞争结果，混合接口可出现高价锚与 undercutting cycles。
  • 优势是 finite-horizon、path-conditioned；realized external regret 不等于让对手重新响应 counterfactual actions 的 policy regret，不能宣称 asymptotic dominance 或一般性 collusion theorem。
方法、证据边界与作者核查

本次读取正文设定、接口比较和 replicated matchup 结果；对价格动态的总结与论文摘要相互核验。单条 illustrative path 不作为普遍规律。改变算法接口、可见信息与调整频率会改变战略行为，不能把 LLM 品牌或能力直接等同于竞争效果。

agent-risk: Risk Assessment for Changes to AI Agents

Yue Zhao / Zixiang Xu / Angela Huyue Zhang / S. Alex Yang / Xiyang Hu

研究问题：企业收紧 agent safety gate、允许被拒后的 retry，或更换模型时，既有 logs 能支持什么风险结论，哪些变化必须增加证据才能审批？
参与者与时序：deployer 定义 loss、gate、允许修改的组件与审批阈值；agent 提出 tool call，trusted monitor 评分，gate 放行、停止或拒绝后继续。比较到新旧规则的 first deviation。
识别与约束：要求未修改组件的机制、随机输入和初始状态 invariant，且 agent 不提前响应未宣布的变更。停止损失必须明确保留此前 harm；继续运行的未支持路径需要 snapshots、额外 runs 或 bounds。
  • logs 将路径分为 agree、stop、continue。retry 不是 stop；若日志缺少拒绝后的行为，用停止规则替代 retry 会误估风险。缺失 harm timing 也不能仅靠增加相同字段的样本弥补。
  • 一个 7,200-episode log 无法单独决定两个 retry gates；从保存状态执行未决 continuations 后，在给定审批规则下得到与 live runs 相同的决定。成本比较以既有 log 已具备为条件，部分 live-test benchmark 为 post hoc。
  • sandbox 示例中，移除 per-step harm 后可认证的 harm ceiling 从 0.064 放宽至 0.159，约为 2.5 倍。该数字不是现实事故率；共享 workspace 和 gate announcement 可破坏简单 replay 或 component-to-system 外推。
方法、证据边界与作者核查

本次读取正文风险设定、日志充分性条件、supported continuation、restoration fidelity、rerun budget 条件与 sandbox 结果。理论的独立 episodes、binary harm 和特定 continuation family 条件不自动适用于任意部署；本文不是 strategic equilibrium。已核验命题条件及正文结论，未逐式重做所有附录证明，不补写一般保证。main study 包含 16 runs、约 49,000 episodes；targeted rerun 的节约不含最初建设 logs 与 snapshots 的成本。

Hongchen Wei / Daohong Ying / Zhi Hong / Aidan Wu / Bei Liu / Ruichun Ma / Yifan Yang / Qi Dai / Kai Qiu / Rui Xu / Dongdong Chen / Zhenzhong Chen / Chong Luo
